# 六类EB必须在生成前落实

用户于2026-10-13确定按EB公开角色实验比例对齐。六类是给定家庭协商政策的类型，仍保留中国城市普通住宅人口/住房约束、每户4–6类EB功能设备、原成熟前端和共享角色回应模型。

| 类型 | 含义 | 1000户配额 |
|---|---|---:|
| A | 通勤、费用优先、先建议 | 166 |
| B | 居家、舒适优先、确认后改变 | 198 |
| C | 作息易变、行动前当天确认 | 125 |
| D | 通勤、边界内自动优化 | 151 |
| E | 照护安全优先、提醒为主 | 156 |
| F | 通勤EV可用性、自动错峰 | 204 |

来源是[EB预印本§5.5及附录表5/7](https://arxiv.org/html/2608.08691v1)的97/116/73/88/91/119，共584名被分配角色的参与者，以最大余数法转成1000户。它是EB实验参考构成。原EB有六类基础角色和五类多成员家庭，不能把两者或六种设备混同。

新的顺序是：**定义与配额 → 联立人口/住房/角色适用条件 → 给定家庭协商政策 → 成员作息与服务 → 通常A及多种B → IDF → 原50户验证 → 完整1000户恢复验收 → 再审查EP准入**。

完整验收同时要求逐户语义成立、精确配额、具体事实能映射到六类，以及不读取类别代码的聚类能恢复六类和比例。单独设k=6或给旧画像贴六个标签不能通过。未知主观态度保留在源证据侧；演员得到的明确偏好属于给定角色条件，接受标签仍来自真人。

[学校预检](EB_SIX_TYPE_PREFLIGHT.json)读回1000个实际世界文件。1000户的相关主观取舍尚未设定；当前严格的成年常住政策责任人适配下，联合配额最多覆盖984户。另16户均为未成年人单人户，其中10户来自15–19岁辅助年龄组、6户来自0–14岁组。严格责任人定义是本研究候选条件，预检不证明这16户的统计源错误，也不允许直接删除它们或改变年龄。部分分配里最后未填满的类型随遍历顺序变化，不能据此断言EV数量不足。

先解决角色代理与家庭适用域，再实现政策到作息/服务的生成与聚类恢复，在原50户验证后冻结生产版本。旧V23验收只适用于旧输入；新要求尚未通过，未生成新版1000户，也未启动新版EP。完整方法见[版本化方案](../research/collection-adjustment-20260930/household1000/eb_six_type_prerequisite_20261013_v24/METHODS.md)。

```bash
python3 scripts/household1000.py status
python3 scripts/household1000.py require-generation
```
