# 六类EB必须先有真实家庭比例依据（V25）

用户澄清：论文分配给演员的角色人数不一定符合真实家庭比例。当前任务改为**先估计中国城市家庭的六类占比，再据此生产1000户**。V24的166/198/125/151/156/204停止作为生产配额，保留为历史实验构成；当前六类比例和人数均为null，新版生成和EP仍关闭。

| 类型 | EB种子政策含义 | 当前1000户配额 |
|---|---|---|
| A | 通勤、费用优先、先建议 | 待真实数据估计 |
| B | 居家、舒适优先、确认后改变 | 待真实数据估计 |
| C | 作息易变、行动前当天确认 | 待真实数据估计 |
| D | 通勤、边界内自动优化 | 待真实数据估计 |
| E | 照护安全优先、提醒为主 | 待真实数据估计 |
| F | 通勤EV可用性、自动错峰 | 待真实数据估计 |

六类是分类框架，不是已证明存在的六个中国自然群体。人口、住房和经济资料可以约束家庭结构，但不能独自识别本人偏好。例如A、D都可以是相同人口结构的通勤家庭，区别在是否允许自动控制。峰谷电价办理意愿也不能替代这项授权。

优先核查能在同一家庭测量关键偏好的权威调查。已下载CRECS2012/2014有峰谷电价办理意愿、调整困难理由、通常空调设定等部分指标；尚未核验到完整六类联合识别所需的授权和服务容忍题组。CRECS后续适应性行为、供暖制冷模块是待审查候选，不能在取得和核验前当作已准入证据。供暖制冷模块的官方覆盖说明是南方城市，不应直接外推全国。

如仍缺联合偏好数据，复用原成熟前端，先让真实家庭**按本人家庭作答**。核验六类映射、家庭户抽样权重、非应答和人口住房校准，估计比例及不确定性；不能按六类等额找演员并把配额称真实占比。MRP只是在有真实偏好回答和总体分层信息时的一种校准方法，不能创造没测到的偏好。未知、混合、无法归类的质量须单独报告。

当前顺序为：**目标群体/年份 → 来源与真实家庭自答 → 验证六类映射 → 家庭户加权比例及区间 → 冻结1000户配额 → 联立人口/住房/设备/政策 → 作息与服务 → 正常A及多种B → IDF → 原50户验证 → 1000户恢复验收 → 再审查学校EP准入**。

不读类型代码的恢复检验只验证生成器遵守已冻结模板；“设k=6能分六组”不证明模板代表真实人口。少见类型可以另设平衡压力视图，与真实占比主队列分开报告。每户4–6类EB设备仍是覆盖设计，需要说明其适用域；不是全国设备自然拥有率。

完整路线、来源审查及缺口见[V25方法](../research/collection-adjustment-20260930/household1000/population_grounding_revision_v25/METHODS.md)与[来源账本](../research/collection-adjustment-20260930/household1000/population_grounding_revision_v25/SOURCE_LEDGER.json)。[EB官方协议](https://github.com/Agentic-Intelligence-Lab/EnergyBridge/blob/2b17ae63e613da776c93e900f5dace50d63a88a8/human_survey_materials/PAPER_CALIBRATION_STUDY.md)也区分真实用户自答的比例估计与后续角色扮演校准，这是方法依据，不能替代真实比例数据。

[V24学校预检](EB_SIX_TYPE_PREFLIGHT.json)保留为旧实验配额下的结构诊断；其984/49可分配容量不是实际类别数量，也不是当前配额验收。V23输入与原50户物理验收保留历史范围。没有新增家庭世界、真人答卷或EP执行。
