# 六类EB的类型覆盖验收（V26）

当前执行结果见[V27方法与验收](../research/collection-adjustment-20260930/household1000/eb_type_pilot_v27_20261014/METHODS_AND_ACCEPTANCE.md)：原50户新版参考验收通过，1000户研究配比A101/B303/C319/D101/E85/F91冻结且保留原50户政策。全量1000静态包与整体实际覆盖仍待验收，1000户EP关闭。下文保留历史实现/方案作来源地图，未完成状态和当前入口以[STATUS.json](STATUS.json)及V27证据为准。


2026-10-14用户确认学长提出聚类的目的：**类型覆盖与EB一致**。当前要求是检查1000户是否在实际家庭任务特征上覆盖EB六类，不再要求先取得全国六类偏好占比。V25的全国比例前置被撤下；V24的演员人数配额也不重新启用。历史版本保留，当前生成与EP仍关闭。

| 类型 | 需要在具体任务世界中体现的区别 |
|---|---|
| A | 规律通勤、费用优先、可移动任务、先建议后决策 |
| B | 主要居家、舒适保护、较受限任务、逐次确认 |
| C | 作息易变、服务时间受限、行动前当天确认 |
| D | 规律通勤、较宽舒适边界、可调任务、边界内自动优化 |
| E | 明确照护与安全服务、较少调节、提醒为主 |
| F | 有可用EV服务及出行约束、可错峰、边界内自动安排 |

聚类用于判断哪些类型缺失、哪些类型重复或过多、区别是否真正进入任务世界。类别代码、模板名、提示词标题、演员答案不能当聚类输入。A和D都可以是通勤家庭，但其控制权限和可协商条件必须不同；F不能只在标题写EV而没有充电服务与离家需求。

先从EB参照和家庭输出提取同口径的作息、舒适、任务、费用取舍、权限、服务资源特征。分别做核心语义检查、参照对应，以及不读类别的聚类；报告六类覆盖、代表家庭、组内变化、模糊/缺失、簇合并拆分和稳定性。设k=6本身不能证明有六种实质类型，也不证明中国家庭自然分成六类。

类型人数属于任务覆盖设计。先核验源家庭骨架与角色适配的联合可行性，在原50户开发后、正式1000户生产前冻结最低覆盖、人数或区间及验证阈值。当前数值尚未批准。人口和住房仍遵循中国城市源约束，排除镇与乡村；不把研究角色偏好写成源家庭真实心理属性。每户4–6类EB功能设备和原成熟前端保持既定任务范围。

当前顺序：**六类参照 → 共同特征与家庭适配 → 联立源结构和覆盖可行性 → 具体角色政策 → 作息/服务与正常A、多种B → IDF → 原50户类型覆盖、物理与原前端验收 → 冻结构成和规则 → 1000户完整输入与覆盖验收 → 再审查学校全量EP**。
