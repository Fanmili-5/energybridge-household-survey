# 已有支撑与仍需坐实的部分

1. 人口与部分住房控制有来源，完整联合及年份/地区运输有假设；4–6类设备属于任务覆盖。22户供水、80户热水、16户非同住协助、8条厅服务柜配置变化留痕，不能说全部住房特征仍为原统计构成。
2. 正常作息和优选时间/温度已经承载部分给定偏好。当前AC默认、洗浴目标和EV目标较集中，总体节费/舒适重要性未知。下一步整理事实、惯常安排、服务要求、可协商偏好、变更代价和未知，并核实际前端可见投影。不按年龄/收入刻板填性格，不预设真人采用答案。
3. 演员固定角色跨情境延续，必要时部分同角色/同情境安排独立演员重复；合法偏好陈述/support先于query。支持k=0，缺失历史不是任务无效。演员意见不等于真实住户意见或角色唯一真值。
4. 保留混合B，补轻微、边界附近、明显冲突和联合代价诊断，以及独立agent/专家提案迁移。比较仅需求/计划、完整角色、角色加合法历史；不能靠发现规则冲突的成绩宣称个体取舍已学会。
5. 收集前锁定演员×角色×事件/版本/顺序/缺失/提示/合法历史及切分，按角色、演员、提案/原型依赖评估。B包含建模使用的所有人类信息，独立测试/试读成本另记；10000相关情境不是10000独立人样本。
6. 物理检查分开计量、服务目标、行程需求和个人舒适。关键组件外部参照与初始化/参数/边界敏感性待补；正式采用的情境核查后果，未知不记0。
7. 原二元题表示原样采用B；不同意原样可能包含修改或缺信息，原因与后续编码分开。四项可空评分为整体、舒适、用电与费用、响应安排；费用未计算，不能把该评分单独命名为费用满意度。

当前依然是参考世界与工程试验，真人0，正式采集/训练/科学benchmark准入false。规则族、温度/分钟水平和5/5配额是设计，不因有方法文献就成为人群实测阈值。

方法参考：[HumanLM/Humanual](https://arxiv.org/html/2603.03303)的画像/训练历史与新情境分离、[CheckList](https://aclanthology.org/2020.acl-main.442/)的能力×测试类型诊断；相关论文没有验证本项目中国家庭或提供正确演员答案。
