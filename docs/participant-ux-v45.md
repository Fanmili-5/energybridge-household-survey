# 参与者问卷与结果页调整（2026-09-14）

问卷 v4.5，页面 v6.9。继续使用同学问卷中的成员事实与偏好结构，对接原 EB 字段；不改变 EB 规划或 EnergyPlus 执行。

## 选项

系统控制原来“先看建议再决定”和“每次先确认”重叠，合并为三个清楚的倾向：约定范围内自动调整、每次明确同意后调整、更愿意自己安排。家庭字段仍对应 `high_trust_auto / confirm_required / low_auto_accept`，成员对应 `auto / confirm / manual`。不推算接受概率或成员评分权重。

成员室温感受区分“较大变化通常能适应 / 仅能接受小幅变化 / 小幅变化也容易不适”；任务时间区分“按时完成即可 / 只接受小幅提前或推迟 / 尽量保持原时刻”。重要程度仍用五档；生活状态、住房类型等分类答案不强行排序。

旧草稿保留事实及不相关答案，重新询问这次变化的控制、室温感受、任务时间偏好。旧提交保留其问卷快照，不把旧选项自动改写为新答案。发布的 `QUESTIONNAIRE_CODEBOOK.json` 从实际运行代码生成。

## 结果页

新结果只有两块比较内容，下面接家庭选择、四项小数评分和原因：

- 一套完整时间坐标，上方调整前、下方调整后。电器名称旁直接列运行时间与设定，无运行记录也明确注明；手机可左右滑动。
- 一张直接展开的表：全天用电量、相对用电成本、响应时段用电量与平均功率、响应前中后室温、任务完成情况。未验证的电动车离家电量和热水满足情况明确标注，不从运行条推算。

删除新结果页的“同一个家庭 · 同一个情境”、EB 逐次复查、重复文字表、单独温度曲线和多层折叠解释。保留判断所需的模拟说明、成本不是人民币、跨夜统计截止等信息。

修复旧摘要按过期指标名取值、总用电和成本只能展开查找的问题。未改变实际仿真数值，也不强迫生成有差异或更省电的方案。
