# 24小时统计与完整时间轴

2026-09-14；用户确认：有EV时按离家时刻起算24小时，没有EV时按自然日。

## 当前口径

- `scenario.statistics_window`：有EV为 `[departure_h, departure_h+24)`；没有EV为 `[0,24)`，10分钟网格。
- `scenario.evaluation_window`：保留仿真/展示覆盖的旧字段名；从0开始，至少覆盖统计终点和已填写的任务期限。二者不再是同一个概念。
- 全屋电量和相对成本仅统计 `statistics_window`。费用逐个EP电表区间乘对应起始时刻的原生电价，再累加；不按总成本比例折算。
- 记录区间采用 `[start_h,end_h)`；筛选结束时间在 `(statistics_start,statistics_end]` 的10分钟电表记录。验证连续覆盖及原生总计一致。
- 响应时段指标保留原VPP事件的时间范围。如果离家较晚，事件可能在24小时统计窗口之外；它是独立事件指标，不冒充24小时指标。
- 时间轴从00:00展示；统计范围外淡化。表格明确“统计时段：当日08:00—次日08:00（24小时）”。
- 截止线处还有运行记录的条带用箭头表示，不称为实际完成。
- EV展示统计终点那次离家前电量，而非任意首次离家。保存统计边界处的电量观测及其时刻。
- 热水需求按钟点投影至统计窗口内，保存绝对时刻；这只是所选周期的需求实例，不改变热水器控制。
- 每天的洗衣、洗碗、烘干任务有独立ID及截止/已完成/跳过状态，并保存统计终点和仿真终点的状态快照。

## 保留的限制

其他电器仍可能跨出统计区间。图中可展示的后续运行不计入24小时表格；不因此声称等服务条件下净节能。保存任务结果供研究者辨识，最终接受/拒绝和评分仍由真人提供。

初始电量仍来自原EB模型的初态设定。统计起点处两条独立策略轨迹的状态可能不同；这里只比较用户看到的两份安排，不宣称同状态单次事件的因果收益。

没有关闭EB次日规划、途中复查或技术回退，没有增加优化器约束。24小时统计不等于只运行24小时；本次不承诺降低模型调用次数。
