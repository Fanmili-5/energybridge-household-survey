# 问卷内容

每户由一人填写家庭情况，代述成员偏好，并在查看模拟结果后给出家庭评价。成员答案是填答者的描述，不等于分别访问了每位成员。

| 部分 | 收集内容 | 用途 |
|---|---|---|
| 家庭概况 | 人数、白天和傍晚是否在家、作息规律 | 构造家庭资料、居家日程与 EB 上下文 |
| 家庭成员 | 年龄段、生活角色、日程、舒适与控制偏好 | 提供成员差异，保留用于后续家庭分析 |
| 电器安排 | 家中电器、平时使用时间、运行时长和可调整窗口 | 生成日常安排及 EB 调度约束 |
| 用电偏好 | 温度范围、费用与舒适的重要程度、自动调整和错峰意愿 | 构造 EB 家庭偏好 |
| 住房情况 | 省市、房型、面积及其计算方式、楼层 | 匹配天气站和住宅原型 |
| 补充信息 | 其他设备及家庭研究信息 | 随答卷保存，供后续分类和分析 |
| 方案评价 | 同意或不同意、四项评分、简短原因 | 作为家庭评价模型的监督目标 |

每个字段的准确选项和映射以 [QUESTIONNAIRE_CODEBOOK.json](../QUESTIONNAIRE_CODEBOOK.json) 为准。字段是否进入 EB、EP 或仅保存用于研究，由其配置决定；并非所有收集字段都会改变仿真。

各填写页和成员页可以自由切换，已填内容保留。最终提交时统一检查必填项和时间约束，发现遗漏会跳转到对应页面。

## 电器时间

洗衣机、洗碗机和烘干机按以下顺序填写：

1. 最早可以开始的时间。
2. 最晚必须完成的时间。
3. 从启动到完成的运行时长。
4. 平时通常开始的时间。

第四项必须满足“开始时间不早于最早时间，完成时间不晚于截止时间”。例如 08:00—22:00、运行 90 分钟，开始时间只能选 08:00—20:30。修改前三项后，失效的选择会清空；窗口不足时会提示重新填写。后端在保存答卷前检查同一约束。

时刻和运行时长按 10 分钟选择，跨日时显示“次日”。空调温度支持 0.1℃。电动车和热水器使用各自的时间字段，不套用上述三个任务型电器的规则。

## 方案与评价

对照方案沿用原 EB 的 No-DR 方法。洗衣、洗碗、烘干在用户允许的窗口内随机安排，并不直接复制“平时通常开始的时间”；该时间仍作为家庭偏好保存并传给 EB。因此，两份方案应理解为本次情境中的日常对照和 EB 调整，不能把对照说成用户填报时间的逐项复现。

参与者查看同一电器调整前后的时间轴，以及电量、成本、室温等模拟结果，然后填写：

| 保存字段 | 含义 |
|---|---|
| `decision` | `accept` 或 `reject` |
| `score` | 整体满意度 |
| `comfort_score` | 舒适满意度 |
| `energy_score` | 用电与费用满意度 |
| `vpp_score` | 错峰安排及自主决定体验 |
| `comment` | 填答者的原文原因 |

四项评分为 1—5 分，允许小数。选择、评分和原因分别保存；系统不根据分数推断是否同意，也不代写原因。
