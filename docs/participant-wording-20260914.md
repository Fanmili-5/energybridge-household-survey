# 参与者页面文案整理（UI v6.12）

参与者页面解释如何填写和评价；模型参数、资源匹配规则及数据导出规则保留在后台。

| 位置 | 现在展示 |
|---|---|
| 月份提示 | 请设想您家在 X 月的一天，按那时的日常习惯填写。 |
| 开头 | 请由一位家人代表全家填写。不需要姓名或详细地址；拿不准的选填题可以跳过。 |
| 住房页 | 请填写所在城市和住房概况，不需要小区名或详细地址。 |
| 城市题 | 找不到所在城市时，可以选择自行填写。 |
| 面积题 | 请按您知道的面积类型选择。建筑面积通常含公摊，套内使用面积不含公摊。 |
| 提交页 | 说明将生成两份安排；看过时间、用电量和室温的对比后，再选择、评分并填写原因。 |
| 体验数据用途 | 本次为体验填写，回答会保存，用于改进问卷。是否参与由您决定。 |
| 正式数据用途 | 您的回答将用于研究家庭用电选择，并帮助训练理解家庭偏好的人工智能模型。是否参与由您决定。 |

保留简短的体验版标识、自愿参与说明及“方案为模拟结果，不会改变家中电器的设置”。删除参与者页面中的工程测试标记、默认导出、气象站和行政区资料年份、面积换算比例、供暖固定参数等说明。

本次仅修改显示文案和 UI 版本号，未改问卷答案字段、日期抽样、仿真与控制、采集模式或历史记录。日期情境和问卷定义继续保留原有快照，避免改写已提交的数据。
