# 问卷两份安排的比较时间：依据与建议

日期：2026-09-14。状态：历史调研。后续讨论已否决统一48h，改为离家至次日离家的24h统计；见 `STATISTICS_24H_20260914.md`。下文保留当时建议，不作为当前运行规范。

## 要解决的问题

目的仍是收集真人对家庭用电安排的接受/拒绝、四项评分和理由。需要两份安排使用相同时间范围，尽量展示第一天任务的跨夜结果，避免将未完成任务或截止线以后的耗电描述为节能。同时保留 EB 每日规划及途中重规划。

本轮是聚焦范围调研，不是系统综述。检索对象为建筑控制基准、DR 恢复期、EV 离家电量约束；优先论文作者稿、研究机构和基准官方文档。只把与时间定义直接相关的内容作为依据，不以论文的一次实验时长代替本项目设计。

## 推荐：固定 48h 的配对观察，加任务结果记录

这是基于当前问卷边界的工程选择，尚未做新协议的配对 EP 验证，不是文献规定。

1. **统一时间范围**：所有家庭均为第一天 00:00 至第三天 00:00；所有主图与总电量/成本使用同一 `[0,48h)`。称为“两天安排对比”，不称“一天总用电”。按两个连续 24h 区段排版，让相同电器的原安排/调整后保持上下相邻。
2. **保留 EB 连续执行**：不关闭次日规划，不清空 EV 电池、室温或水箱状态，不人为禁止次日任务。第二天的新任务如确实执行，其区间用电进入 48h 总量。
3. **区分任务实例**：第一天的洗衣、洗碗、烘干、EV 接入等分别有任务/会话 ID、绝对起止和期限。与第二天新增任务分开保存。EV 第一日凌晨的在家充电单列为初始会话，它来自初态假设；其实际区间用电仍计入总量，不能事后随意扣除。
4. **记录结果，不替真人评分**：记录是否完成、实际完成时间、期限时电量/目标、未完成量。到期未完成属于实际结果，可以供用户拒绝和打低分；不自动修正成合格计划。热水需求须先补齐日期归属，空调还须记录室温与舒适度轨迹。
5. **截止与完成分开**：运行跨出 48h 时标为“仍在运行/尚未完成观测”，不能画成恰好结束；未来计划只能标为计划，不能伪装成实测仿真。保留 48h 时 SOC、水温、室温与待完成任务，以便识别边界差异。
6. **限定能耗结论**：48h 总量是这两天观察到的用电，不能自动解释为同等生活需求下的净节能。任务没做完或终态明显不同，可照实显示用电与服务结果，但不能仅凭耗电少宣传方案更优。真实人民币电费仍须另行确认电价单位，时间延长不会解决单位问题。

任何有限窗口都会截到循环生活中的新任务。该方案保证的是“每户等长、第一天合法期限可观察、未完成不冒充完成”，不是“所有未来任务都结束、所有热回弹都消失”。若坚持一次问卷只评价一个 24h 生活周期，就必须另行定义目标任务归属与尾段核算；不能一边保留原生循环任务，一边仅靠换个切点声称没有截断。

## 不选择的方案

| 方案 | 本轮不采用的原因 |
|---|---|
| 00:00–24:00，或 08:00–次日08:00 | 换切点不能覆盖所有家庭的跨夜窗口；后者还会排除当天08:00以前的执行 |
| 每户到自己的最后期限为止 | 户内公平，但跨户时长不同，原始总量和评分情境难以统一 |
| 固定32h/36h | 不能覆盖当前可填的晚截止时间 |
| 一直跑到所有任务完成 | 原生 EB 每天产生新任务；不保证存在这样的停止时刻 |
| 到截止线以后不计成本，只补画时间轴 | 图和主指标口径分离，可能使延后耗电看起来更省 |
| 强制所有任务在固定截止前完成 | 改变 EB 策略可行域，并削弱不合格策略的真人评价样本；未获授权，不做 |

## 落地前必须通过的检查

- EV 22→08、23:50→23:40；移时任务午夜前后、次日很晚期限；到期不达标；第二天新任务跨第三天。
- 各设备每个10分钟能量累加、两日分段和48h总量一致，端点既不漏算也不重复。
- 显示的结束时间来自实际停止/完成，截断状态明确；首日任务和次日任务不混淆。
- 图、总量、真人作答时看到的信息快照、SFT 候选输入全部对齐同一协议版本。
- 两个分支使用相同天气日期、任务需求、初态、计费函数、统计边界；保留整个决策日志。当前若两分支从0h独立规划，则结果是两条策略轨迹对比，不能额外声称是同一 VPP 时刻状态分叉的纯因果效应。
- 用固定规划输出/模型桩和真实 EP 做新窗口验收，另测运行时长；暂不消耗付费 API。延长评价可能增加第二天重规划调用，不能只按 EP 仿真秒数估计延迟。
- 即使窗口改为48h，上一轮审计提出的热水日期歧义、显示快照与导出一致性仍须单独修复。
