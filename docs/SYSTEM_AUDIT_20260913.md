# EnergyBridge 问卷系统检查记录（2026-09-13）

> 历史记录，保留当时的测试结果和设计依据。项目使用说明见[文档目录](README.md)。

## 结论

当前主线可以用于**受控工程演示和小规模试采准备**：真人家庭资料独立保存，原 EB `no_dr` 与 `agent` 两条路径在相同研究住宅、天气、日期、价格和一天时域内运行，EnergyPlus 24.1 生成两份结果，最终 `accept/reject`、四项小数评分和原因只由真人填写。

当前不能宣称“全国全年、50 人同时进入后都能及时获得真实模型结果”，也不能把候选 JSONL 直接标为正式训练集。主要边界是全年住宅—天气组合尚未逐组合验证、真实模型供应商的延迟和费用没有在本轮无付费测试中测量、备份仍在同一台网站服务器、学校计算副本尚无确认后清理机制。

## 本轮修复

- 问卷版本升级为 `eb.persona_questionnaire.v4.3`，成员列表成为必需家庭结构；成员扩展题保持可选并收起，减少页面长度。
- 参与者实际看到的 `participant_view` 完整冻结；SFT 消息从该冻结视图生成，保存服务端认可的 UI 版本。
- “没有纳入这些设备”只保存问卷，不启动无意义的模型和 EP 任务。
- 候选导出逐文件验证运行目录；新增两支 EP 电量/室温标准时序及 `eplusout.err` 哈希，缺失证据的真人候选不通过。
- 家庭探索性聚类从权威 SQLite 的全部真人 intake 读取，包含未生成或生成失败的问卷，避免按 EP 成功与否选择样本。
- 采集漏斗修正月份来源，并增加决定分布、四项评分、评论长度、方案是否变化、原生回退和失败状态统计。
- 问卷保存增加普通会话 5 份、UTC 每日 2000 份的独立保护；计算仍使用独立的会话、队列和每日额度，幂等重试不重复计数。
- OpenAI 兼容 SDK 的隐藏重试设为 0，保留原 EB 明确的重试循环；新增 UTC 每日逻辑模型调用账本。
- Nginx 模板的普通请求突发额度调整为 300，并为限流返回 JSON 429。
- 发布后的零网络验收发现旧 `ep_only_benchmark.py` 仍调用历史四日自定义闭环并硬编码第 4 天；生产采集不走该脚本，但会误导运维验收。该脚本已改为直接执行正式单日 `no_dr` / `agent` 入口，以固定无效模型回复触发 EB 技术回退，全程禁止网络且不生成真人标签。

## 无付费验证证据

- 完整离线回归：185 项通过，包含 EnergyPlus 24.1、四季代表日期、地区/住宅、队列、恢复、数据导出与安全边界。
- 浏览器全流程：390px 和 1365px 均完成六页问卷、真实 EP 工程替身、两份时间轴、小数评价和刷新恢复；自动可访问性扫描通过。
- 50 会话工程容量：本轮 50/50 完成，提交 P95 约 0.75 秒，重启恢复 50/50，重复请求去重 50/50，跨会话访问被拒绝；16 worker / 16 EP 槽、无模型网络，计算与反馈整批约 18.37 秒，产物约 674 MiB。
- 该容量测试只证明本地 HTTP、SQLite、EP、队列恢复和固定模型替身链路，不代表真实模型延迟。
- 密钥扫描：当前跟踪文件及 Git 历史未发现已知密钥格式。
- 单日生产入口工程验收：`no_dr` 与 `agent` 各运行一次 EnergyPlus；固定模型回复共进入 8 次 EB 显式尝试，外部 API 调用 0，评价保持 `human_evaluation_pending`。

## 正式分发判定

1. **现在可以做**：管理员和同学的工程演示、少量不计入正式数据的完整试填、前端理解测试。
2. **小规模真人试采前**：确认研究说明与数据保留口径；做 3—5 条经授权的真实模型样本，记录逻辑调用数、底层尝试数、token、费用、等待 P50/P95、回退率和无变化率。
3. **扩大到约 1000 户前**：增加异机备份与磁盘报警；定义学校副本确认/清理；按季节、地区、住宅、设备统计 intake→仿真→评价→候选各阶段成功率。
4. **训练发布前**：冻结版本和样本清单；按家庭代理分组切分；排除证据不完整样本；保留失败和无变化案例的统计，不按接受、节能或规划质量挑选数据。
