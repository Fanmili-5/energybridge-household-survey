# 免登录填写与本地图片验证码

参与者直接打开问卷填写。浏览器的匿名会话用于恢复本人资料和任务，不再要求共享用户名、密码。保存家庭资料不弹验证码；生成两份方案前输入 6 位图片字符，再由后端决定是否接收计算。

- 验证码是后端生成的 PNG，答案不写入网页、返回 JSON、日志或研究样本。
- 绑定浏览器会话和本次提交标识，3 分钟失效；不区分大小写，连续错 3 次后失效，可换一张。
- 验证通过即消费，其他会话或新请求不能重复使用。相同请求重试返回已创建任务，不重复调用模型；验证码字段不参与研究记录或请求内容哈希。
- 生成失败或验证码服务重启后可以重新验证；已保存的家庭资料不丢失。
- 图片验证码只能拦普通脚本，不能防现代 OCR，也不能证明“一人一份”。保留每浏览器会话生成次数、全站每日额度、排队上限、超时，以及 Nginx 会话/验证码/生成限流。同一校园出口允许一定突发请求，不能直接把 IP 当个人身份。

管理员从 `/admin/` 登录，进入 `/admin/survey` 测试。管理 API 走 `/admin/api/...`；公共接口一律清空代理认证身份，即使请求携带管理员名字或 Basic Authorization，也不会获得权限。管理与参与者的草稿使用不同命名空间。管理员仍受队列和计算资源限制，测试数据继续单独标记。

## 部署

后端增加 `--local-captcha`，再启用 [Nginx 配置](../deploy/nginx.conf.example) 中的公共入口与独立管理入口。后端仅监听回环地址，外网只能经过 Nginx。不要只删除全站 `auth_basic` 而继续把公共请求的 `$remote_user` 当作管理员身份。

未增加第三方服务、密钥或新 Python 依赖。验证码状态只在当前网站进程内存中保留，最多 5000 条、每会话一条；进程重启会让旧验证码失效。研究 SQLite 数据格式不变。

## 验证

- 离线 192 项测试：184 通过，8 条条件测试跳过。
- 错误/过期/复用/跨会话/跨提交的验证码被拦截；缺验证码不创建任务；已接收请求重试幂等。
- 390px 手机、1365px 桌面完成图片验证、真实配对 EP 固定替身计算、时间轴、反馈与导出。测试数据库临时创建，不混入研究数据，付费 API 调用为零。
