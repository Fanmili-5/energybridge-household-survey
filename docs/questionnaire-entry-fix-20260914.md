# 问卷入口与历史结果恢复

> 历史记录，保留当时的测试结果和设计依据。项目使用说明见[文档目录](README.md)。

2026-09-14，UI v6.18。

原问题：同一浏览器只要有历史任务，首页就自动加载最近的任务并隐藏问卷；已完成记录会直接滚到方案比较，用户无法理解为什么跳过填写。

修改后，已完成或失败的记录不再自动取代问卷。首页先展示家庭信息，并提供“查看上次结果并评价”或“查看已保存的评价”按钮。正在排队、运行以及提交响应丢失后的恢复仍沿用原路径，避免重复生成。未提交的评分草稿和已保存评价均保留。

验证：390px、1365px 隔离浏览器回归通过，覆盖问卷、验证码、原生EP固定规划、结果导航、小数评分、刷新回到入口及主动恢复评分。没有付费API调用，没有使用真人标签。同步修复两条仍引用旧统计文案的测试断言，未更改统计规则。

发布：云端和计算端均切换到 `entry-v618-20260914`；计算代码哈希为 `e8bc9927830213ee6c5ce75485bb6e2c5666aeccbf27287c4c6d0243e40280fb`。保留旧发布与数据备份；数据完整性比对、线上静态文件一致性和免登录会话检查通过。采集模式仍为 engineering。
