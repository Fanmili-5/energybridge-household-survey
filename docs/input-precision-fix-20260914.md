## 执行层

`native_clock.py` 只包装活跃仿真的电器执行：区域步边界推进一次电器模型，HVAC 子步保持上次功率和全部设备执行器值。浮点比较容差为 1e-9 小时。原 EB 规划函数、校验和预测用临时模型保持原样。

规划可能给出 18:12：原始计划仍保存 18:12，在当前十分钟仿真网格中实际从 18:20 执行。未把它伪装成按原时刻准确启动，也未擅自把 EB 计划改成整十分钟。每次分支新增 `appliance_clock.json`，记录执行策略、区域步、保持次数和功率变化，并纳入结果文件哈希。
