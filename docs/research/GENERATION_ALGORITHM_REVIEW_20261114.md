# 家庭与A/B生成算法：修复、复用与审稿自查

本次验收对象是“从支持的调查源池或冻结家庭生成原生A/B材料”的算法包。所有实际计算在天大服务器新隔离目录完成，受控源数据、旧10000题、既有线上50户和已接受物理记录均保留。

## 原三项问题与修复

| 原问题 | 修复 | 验证 |
|---|---|---|
| 配置写20，A程序实际仍用固定5 | 日常入口将A_deterministic_time一直传到实际CpSolver；旧直接调用保留默认5 | 配置穿透测试及新批次每日A_solver_execution |
| 搜索未解决一律写成无解 | 分开UNKNOWN、FEASIBLE未证最优、声明程序域INFEASIBLE、MODEL_INVALID；失败记录保留日期与原因 | 注入四类状态检查，无任务删除或质量要求放宽 |
| 缺口补候选依赖服务器临时脚本 | 公开candidate_completion，封装根动作补齐及洗烘依赖补齐；统一编排覆盖重选和当前索引封存 | 完整公开示例、隔离目录及生产规模复现 |

独立复现还发现联合重选中的集合顺序会改变同分解。已固定约束遍历顺序；原生动作、A目标和选题覆盖目标不变。代码、配置、求解器版本和实际计划哈希分别固定。

## 可复用算法及采用范围

完整[算法1](../../benchmark/ab_generation/ALGORITHM.md)给出输入输出、阶段目标、软硬约束来源、预算、状态、命令、代码对应和扩量验收。统一入口支持授权八国调查原件、已规范化源池及冻结家庭；公开合成示例不需要真实调查文件。日常A、有限原生动作B、覆盖补候选、每日一个B、跨户保覆盖重选和当前封存由同一命令完成。

本项目采用分阶段的配额、排程、IPOG-C式覆盖与整数规划；贡献可落在调查约束的决策任务、原生计划合同、可复核材料和后续评测。不能将已有求解器组合声称为新的通用优化算法。每户十题、当地18—19时事件、十分钟网格及既定参考设备是已声明范围。

## 本次实测

- 冻结1000户输入不变，新目录完成10000题、20000次原版电器执行回放及当前索引封存；全部10000个A实际预算为20，程序求解状态均为OPTIMAL。
- 两份独立目录分别从公开合成源池生成96户、960题；PYTHONHASHSEED分别为1和23，960个A和960个B实际指令哈希全部一致。独立目录仅含两个公开包，旧私有工程文件读取被拦截。
- 选题前原始分母保留：949/969细分格入选，945/969跨国目标达成。未覆盖项保留在账本，不当作物理不可能或居民拒绝。
- 57户的事件关联B题未修改到全部受控类：53户涉及烘干缺口、4户涉及EV缺口。这不是A/B日常使用缺失，不能声称每户十题都修改过全部4—6类电器。
- 保留1743个名义事件减电为负的B和6181个热后果未知的B；两类可重叠。未使用真实后果或接受标签选题，这些计数不是物理或人的评价结果。
- 回归分别在相应进程环境中通过：native_contracts 169项；unified_all 135项；research_delivery_all 62项；household 23项；project_interfaces 57项。分组计数有交叉，不相加冒充独立测试数。早期混合解释器诊断曾报错，小模型复现了同进程更改HiGHS线程设置的同类报错；新进程家庭23项通过，完整配方每阶段使用独立进程。

与原冻结批次比较：初选10000个A和10000个B全部相同；最终A相同10000/10000，B相同10000/10000。最终实际计划完整复现，元数据和gzip文件身份单独记录。

本次没有新增EnergyPlus运行、真人标签、模型调用或训练。此前两组物理试例仅按确切A/B哈希核对继承资格，不将其当作全量物理验收。聚合证据见[机器可读验收](../../benchmark/ab_generation/validation/generation_algorithm_package_20261114/RESULT.json)。

## 审稿式自查结论

**通过本轮可复用生成模块验收，可以作为后续benchmark材料构造的入口。** 三项缺陷均已修正，配置、状态、公开实现、执行证据和复现方法对应；负面取舍未被接受率过滤，覆盖分母未缩小。

论文应准确表述为调查约束、原生动作对齐和覆盖引导的情境构造。它不证明全球家庭联合分布、所有动作组合覆盖或真实偏好效度；联合重选日志中的最优状态对应当前家庭的新增覆盖目标，不是全部家庭或二级最少换题的全局最优证明。

进入正式发放仍需：确切方案的配对物理后果、价格/补偿口径、UI91同版呈现与小规模真人检查，以及按家庭/共享来源/配对组隔离的评测划分。真人标签反映参与者在给定家庭情境下的判断，不直接等价原调查家庭的实地接受率。上述工作分别验收。
