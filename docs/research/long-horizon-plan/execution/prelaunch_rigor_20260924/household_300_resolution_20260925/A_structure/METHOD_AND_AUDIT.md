# 300 户家庭结构：已选方法与验收

## 已选方案

从已冻结的 300 个 `cityrole` 读取七普城市家庭人数×代际设计、178 个独立于建筑目录抽出的行政城市、省×代际 H7 房间配额及省级 H6 人均建筑面积分箱多重集。CHNS 2015 城市点有效同户样本 2,198 户中，按人数×房间格抽取每人使用面积的**相对秩**，仅用它在同省排列 H6 分箱；不把 CHNS 使用面积换算成建筑面积，也不使用 1.33。298 户的原房间/人数格样本量≥10；另 2 户原为稀格，最终通过同省×代际房间交换消除。所有逐户 H6 配对均为实验设计，省级 H6 与省×代际 H7 的整数配额保持不变。

对 2 户原稀格角色，先在同省×代际层与另外 2 户交换 H7 类别，再从本地哈希校验的 CHNS 原始文件重算这 4 户在**新人数×房间格**下的条件秩。新格样本量依次为 `0024=17、0267=56、0140=52、0089=69`；四户均有 n≥10 同格。然后对全部 300 户使用确定性的最小成本分配，在同省 H6 分箱配额不变下处理建筑面积与**最终 H7 房间数**的明显冲突。约束是**角色卡的几何常识筛网**：2/3/4/5 间自然房的本户面积下限分别 20/35/45/60㎡；可解释为每个自然房约 7–8㎡加厨房、卫生间、公区份额，未当作法规或调查测量。1 间户的 110㎡上限和家庭 350㎡上限是有限仿真原型及可扮演场景的设计边界，不是物理上不可能的断言。敏感性显示把单间上限收紧到 90㎡仍有 4 户需要再配对，放宽到 130㎡则为 0。生成器保留所有调整记录。

闭合 H6 分箱取中点；“8及以下”取 8，“70及以上”取 75㎡/人。它们是已声明的**设计数值**，不是开口分箱均值。H6 指本户建筑面积：27 户数值 <30㎡ 时设为**合住户**，面积是独用房间加公共部分分摊，`physical_whole_dwelling_building_area_m2=null`。其余 273 户为独立住宅，整套建筑面积取设计值。公开七普 H6 说明允许合住户按此口径填报；CFPS 2020 问卷把 30㎡作为软核查，因此我们将其用作明确住房形态的触发线，绝非中国最低住房标准。

精确年龄由固定哈希在原年龄带内生成，父/子及祖/父/子至少差 18 岁，配偶与兄弟姐妹的年龄差有约束；每个成员关系已明确。精准年龄和关系补全不冒充调查。城市分配保持 UN 城市人口代理与行政区匹配，`city_population_weight=null`。

## 范围与剩余具体问题

- 这是可扮演的合成结构包，不是全国多变量联合样本；城市人口代理未成为家庭户抽样权重。
- CHNS 只给 2015 局部未加权使用面积/房间相对秩，不能验证 2020 H6×H7 全国联合关系。CFPS 2020 建筑面积字段更近 H6，但公开数据需账号审核，本轮未获同户面积×H7 数据。
- 对 27 户合住案例，A 可明确本户 H6 类面积份额与独用间数，不能从七普边际推得整套合住单元面积、共住他户人数或 IDF 热区面积。C 需以物理建模说明覆盖范围；B 应明示合住情境。
- 建筑原型是否支持 322.5㎡上限及合住部分模型，由 C 的真实几何和运行检查决定；本结构验证不等于物理校准。

## 复算与冻结文件

生成器需要 Python 3 与 `pandas`，并会先校验本地 CHNS 家庭/名册原始文件的既有 MD5。这两个 `.sas7bdat` 原始文件须置于仓库根目录下、Git 忽略的 `artifacts/private_research/chns_joint_probe_20260925/`；它们不并入家庭包。使用具备上述依赖的 Python 环境，先进入本文件所在的 `A_structure/` 目录，再运行：

```text
python3 build_family_300.py --verify
python3 validate_family_300.py
python3 audit_sensitivity.py
```

`build_family_300.py --verify` 只对照现有冻结文件，不重写它们；若没有本地 CHNS 原始文件，可只对已生成的 `family_300.json` 运行后两项结构/敏感性检查。`audit_sensitivity.py` 会重写 `area_sensitivity.json`，复核时应比较其下列冻结哈希。冻结 `family_300.json` SHA-256：`d8446c68dd81fa6865cb79add18602fa609188b18631b4134c315385a90ad810`；`distribution_and_anomalies.json`：`dadf52b6bb6957b0bfc4d7f516c00f24b5e3df039dad8b025a52d601e335101b`；`area_sensitivity.json`：`4788dfaf591866ad3bfbe8366c9910749fcc4a739ae72b0ca692f13438512d6c`。七普 PDF 的页码、短摘录与哈希见 `CENSUS_H6_EXCERPT.md`。
