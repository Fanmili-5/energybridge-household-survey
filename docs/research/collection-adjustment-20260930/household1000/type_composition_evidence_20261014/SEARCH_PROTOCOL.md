# 六类构成的定向证据审查

审查日：2026-10-14。范围：截至审查日可取得的官方调查说明、问卷、统计发布与原始研究论文；这是定向范围审查，不声称完成系统综述。

目标总体为2020年普查统计“市”的普通住宅家庭户，排除镇、乡村及集体户。生成对象为1000个可扮演家庭任务世界，每户10个日期的A/B情境。目标是EB六类实质覆盖，同时保持可核验的中国城市家庭结构；不把EB演员人数分布当中国人口分布。

逐项审查：家庭单位/居住与经济口径、城市/城镇范围、调查年份、抽样与权重、就业与日程、真实照护、EV与充电访问、温度习惯/可让渡范围、错峰、自动控制授权。仅具有单轴测量的调查不用于直接估计六类联合比例。

检索源：国家统计局、CHFS、CRECS/CGSS、CFPS/CHARLS、出版社与大学作者稿、原EB论文与协议、人口合成方法原始论文。

检索中英文概念：全国时间利用调查、家庭结构、城市家庭户、家庭能源消费调查、分时电价意愿、热舒适、自动控制授权、照护、新能源汽车、家庭充电；China household demand response/time-of-use/thermal comfort/automation control/population synthesis/IPU/statistical matching。

纳入：可确认作者/机构与时间，能核对变量或统计口径，支持至少一个明确生成约束。区分全文、官方摘要/发布、仅索引。排除：非中国数据作为中国比例；一般人际信任作为自动授权；车辆存量直接转户比例；年龄直接转照护；个人参与率直接转家庭率；仅生成标签或负荷曲线作为角色效度证明。

证据等级：同总体家庭口径直接约束；历史或地区或单轴辅助；方法依据；研究设定；不可识别。公开输出仅来源说明、汇总约束与设计，不转移许可微观数据。

输出：来源台账、可用比例/不可用比例、1000户生成与分配合同、敏感性方案、审查与后续实现状态。所有生成/全量EP准入保持关闭。
