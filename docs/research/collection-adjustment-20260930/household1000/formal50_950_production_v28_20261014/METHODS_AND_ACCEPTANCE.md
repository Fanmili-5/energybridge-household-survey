# V28：1000户完整参考任务世界与50/950正式采集版本

目标是让真人扮演有来源锚点、内部一致的中国城市普通住宅参考家庭，对B相对于正常A的安排评价，支持一个共享的角色回应模型。人口框限定2020年中国大陆城市普通住宅家庭户；排除镇、乡村、集体户及非普通住宅。这里没有把1000户合成参考角色当作1000个实际住户的日记或同意记录。

## 本版结果

1000个世界、2524名参考成员、10000组A/B、20000份基准执行IDF完成静态验收；实际特征的六类覆盖通过。原50户500基准配对和200前史/入水/空调模型敏感性配对先验收，之后才核验其余950户9500基准配对。新增520组天气敏感性，合计10720组配对、21440个输入绑定运行侧。A的热水、车辆可用/出行/储备、住宅与回路功率验收均无失败；通知前输出、计量与逐室/逐人时序闭合均通过。B的不满足结果保留。

这21440侧包含精确相同旧输出的复用与新EP运行，不能全部称为新启动的引擎次数。复用仅在IDF、天气、引擎和SQL字节hash一致时允许，所有侧均依据当前账本重新核验。失败原件与修订前的报告/账本留档，未删户、改日期、换配比或抹去Severe/Fatal。

最终页面的500/9500条案例分别逐条核验世界内容、A/B文件、SQL回读内容hash、物理状态与数值。两包不相交，每户十日期，待计算案例数0。采集接口在专用虚构测试库中通过分户身份、参与说明、来源/显示输入、空值、小数评分、重复提交、修订、恢复和撤回检查；测试不产生真人标签或写入正式库。

## 三处基础修正

1. 全员日程：保留外出区间；可选在家活动只占在家部分；必须在家活动若覆盖外出直接拒收。起床后准备和个人晚餐按本人出入协调。全部1000户/30000个日期日程核验，未改源画像或冻结比例。
2. 气象：98份原EPW中9份有RH超出EnergyPlus24.1字典0–110的值；仅修正470个超限小时，最长段7小时，涉及52户。原件不动，参考使用上一有效值并标E9；独立插值标B9。头部、干球、其余气象量、IDF与原日期不变。所有受影响户的十日期都检查；520组最大A减B电量差变化约3.78e-10 kWh。该结果是所检查任务的模型敏感性，不证明原气象实测正确。依据：[缺失值](https://bigladdersoftware.com/epx/docs/24-1/auxiliary-programs/missing-weather-file-data.html)、[标志](https://bigladdersoftware.com/epx/docs/24-1/auxiliary-programs/data-sources-uncertainty.html)、[24.1官方字典](https://energyplus.net/assets/nrel_custom/pdfs/pdfs_v24.1.0/AuxiliaryPrograms.pdf)。
3. 人员—SQL接口：显式保存外部照护/装取人员的实际输出名称，避免JSON排序改变对应；所有20400份IDF字节不变。无人空间仅在账本全零、IDF无People组件、SQL非部分缺失时证明为零，非零或应有组件的缺失拒收。逐人和逐室时序均核验，带五项反例控制。

## 采集与科研边界

原前端保留采用判断、四项可空评分与原因，增加本人年龄/性别，动作简略且可展开，影响保留。`respondent`及`response`在模型输出侧；实际可见角色/任务字段与合法历史在`input`侧。实际浏览器中改变本人信息和当前回答的两条测试修订，角色字段无变化；虚构测试记录排除在正式导出之外。

正式记录与旧工程数据库独立，包含随机参与编号、角色/日期、源版本与页面hash、参与说明与回执。恢复跨设备身份；同日修订追加，导出取最后一次；撤回排除全部答卷。源情境的`human_label_count=0`保留，实际提交在外层标注参与者来源；未验证个人身份，不将测试、仿真或缺失值变成人类观察。详细实现见[正式采集说明](../../../../../deploy/formal_questionnaires_20261014/RELEASE.md)。

正式发布指可以启动实际角色答卷收集。尚未取得真人角色理解/作用、自然六类偏好占比、品牌设备校准或最终benchmark性能证据。50/950也不是天然独立的训练/测试划分；后续按角色、填写者与来源/模板关联分组设计评测。原空调截断和警告继续公开，模型温度不等于主观舒适。
