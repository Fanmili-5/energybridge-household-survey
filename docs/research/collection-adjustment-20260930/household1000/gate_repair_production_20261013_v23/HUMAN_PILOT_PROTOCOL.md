# 原前端试读与角色有效性采集合同

实验单位是固定给定角色×抽取日期：十题中成员年龄、关系及照护阶段不随日期成长，当天作息随日型变化。这不是实际家庭全年追踪。试读包预留8个角色、16个题、10个独立演员名额（含2个角色重复）、20次A/B回答；名额与空表不算已招募或已取得反馈。事实理解题在同一名额的全部原始A/B回答之后完成，避免提前提示后续选择。

此文件是可执行的采集材料，不是已取得的真人证据。实际答案和试读记录当前为0。复用原前端的二元是否采用、四项可空评分和原因；在原因中允许写修改条件、不确定及协商建议，不把这些文字事后自动等同同意。

先用原50户中的预指定角色做试读。角色材料与任务消费者JSON绑定到世界和方案hash，读题后记录：常住人数和成员关系是否读懂；谁能操作设备；本日与跨夜服务期限；程序结束、取出衣物、可穿、SOC参考目标与实际行程的区别；27℃控制边界与主观舒适的区别。核对答案只依据给定事实，不依据演员应当接受哪套方案。记录误解、漏读、界面错误、澄清次数和材料版本。

角色作用的验证先固定对照再招募：同一服务需求、A/B、参考后果，比较完整角色材料与只含需求及操作可用窗的材料。完整材料增加成员关系、通常作息、照护安排和习惯；对照不隐藏判断技术可行性所必需的事实。采用独立演员分组，避免同一人先看完整角色再看删减材料产生记忆污染；顺序随机化与演员安排事前存档。

预先登记两个问题：完整角色是否减少事实理解错误；是否增加解释中对给定角色事实的准确使用并改变条件性取舍。答案变化不是必然验收条件，不能要求每个角色不同答案，也不能把“使用角色词汇”单独称为行为有效性。另在独立留出回答上比较需求/方案基线、加角色、加合法历史的预测表现。演员扮演结果是角色代理证据，不是中国真实家庭偏好调查。

正式收集保持同一演员连续扮演同一角色的原十个随机日期；预指定少量额外演员重复同角色，分别估计同角色跨演员差异。不能强制相同回答。画像、试读、偏好事前陈述、训练、校准、选型和支持历史全部计入总人类反馈预算B；允许k=0，没有历史时不能虚构历史。

划分提前锁定角色、演员及提案机制的留出规则；同户十题不是独立样本。测试回答不能回填到测试画像或用于改测试提案。事实显示、保存绑定或理解核验失败可按预定规则标记；不同意、条件多、评分反常不能作为删答理由。

试读记录表至少包含：anonymous_actor_id、role_id、case_id、world_sha256、pair_sha256、consumer_sha256、材料版本、分组与顺序、事实理解题与原始答复、澄清/误解、原始采用/评分/原因、缺失原因、先前同角色合法历史、是否用于材料修改或模型选型、feedback_budget_cost。收集后保存原始文本，保留未知；设计标签、内部冲突注释与期待回答不显示给演员。

现有`frontend_release`为原前端的数据接入候选，原线上版本保留。需要实际真人试读记录才能验收角色理解和效度，不使用工程提交或模型生成答案补缺。
