# 1000户完整数据生产逻辑链条（V23验收修订，2026-10-13）

V23不重采样V22的1000户、原十日期、服务需求或A/B。数据合同继续兼容v22；验收代码和发布版本为v23。三项修复为实际内容及依赖核验、冻结原50完整运行集合验收、A住宅和回路功率硬验收。全量1000户EP保持关闭。

启动批次前后核完整内容，每个任务运行和回读前另核本户世界、方案、账本、IDF、天气及代码。旧SQL只有同IDF、天气、引擎和SQL哈希证明一致时可复用，保留旧回执来源，再按当前账本重新回读；不沿用旧接受结论。原50的7/14日前史、入水和单位温度修正诊断不改变原EB参考模型。缺失、重复、失败或范围外结果、A服务或功率失败均阻断接受；坏B保留且不预贴人类拒绝标签。

本版本用于生产**可追溯、户内一致、供真人按给定角色判断A/B的参考任务世界**。总体锚点是2020年中国大陆31省份的城市普通住宅家庭户；排除镇、乡村、集体户和非普通住宅。1000户并非1000条真实家庭记录。统计代表性只按已落实的普查控制量表达；4—6类设备、精确作息、服务期限和协商取舍没有全国实测联合分布。

研究目标为学习一个共享模型：给定角色、合法可见历史、当前状态、B相对A的改变，预测独立真人演员的采纳、评分及解释。人口属性帮助规定角色和资源，不直接规定态度。实际住户同意概率、真实负荷预测和测得电量的Phase-2是另一个研究对象。完整机器合同见PURPOSE_CONTRACT.json。

## 一条逐户依赖链

人口/住房统计框 → 整户联合名册 → 可容纳该名册的住房/床位/设备 → 日期化个人与家庭共同日程 → 先于计划的服务目的及已给定资源 → 连续可执行的A → 只改请求的B → 共同因果执行账本（插拔枪/实际出行/充电/SOC一处计算） → 同账本IDF → 有边界的模拟后果 → 同事实的角色卡/原问卷/合法模型输入 → 后续真人回答。

每个箭头必须有输入内容hash和规则版本。不能用来源家庭缺项补成观察事实，也不能用旧SQL补新世界。名册、工作、洗浴、设备或控制改变，受影响下游一律重生成。V20的812个洗浴协助工作覆盖片段作为失败见证保留，V22更换共同规则并重建，未按单户手调。

V21追加合成机制反例发现：插枪阻止出发后，车辆实际在家，但旧人工操作检查仍用计划行程判“不在家”。原50实际B尚未触发未交付行程，不能据此认为该机制正确。V22将所有设备人工资源、插拔枪、出发、充电/SOC放在同一时间有序账本，编译器只读取其结果，SQL回读再独立核能量。相关反例与回归另存，不伪装成真人数据。

## 谁的“需求”和“偏好”

常住人数、代数和H6/H7为统计/来源/匹配量；居家工作或未知事务是明确活动情景；指定洗浴、洁净批次、次日用车等是本次扮演必须理解的给定条件；习惯时点为通常安排；是否愿意晚一点、用额外协助、接受更高空气温度、改变服务条件，等演员自己表达。给定26℃、27℃控制边界、85%SOC和服务期限均不能称为实测偏好。

例如：给定一位成人在17:00仍居家工作，儿童此时洗浴需要协助。生成器应找到另一位确实有空的成人、合法稍后的共同洗浴时段，或明示已约好的外部协助；不能把“在家”当“有空”并删除工作。B若再请求改变装载或取物时间，须检查同一人的日程及既有协助，而演员仍可评价不便、要求协商或拒绝。

## 空调、电量和真实世界外推

原EB容量、COP、风机及曲线不随模拟结果调参。温度修正函数的原范围为室内湿球12.77778—23.88889℃、室外干球21.11111—46.11111℃；固定EnergyPlus引擎会截断范围外输入。原50的V20诊断已发现实际越界，故V22不能写“原曲线适用域全部通过”。输出只能解释为该明示数学参考模型下的结果。范围外真实设备性能、品牌节能、真人舒适仍未识别；更换为单位温度修正只用于模型形式敏感性，不能称作已拟合替代曲线。

08:00至次08:00是完整观察日；跨夜合理保留，并显示后续取物/用水/出行。有限尾段结束的空气温度、水箱温度和EV储能分别记录。未交付行程或低末态不能被包装成等服务净节能。补至A储能的电量只能给明确效率下的解析估算，不声称已仿真恢复。

## 科研审查判据和真正的下一阶段

生产层可以支持“统计有锚点、给定条件一致、可重现的参考角色任务集”。它不能支持“全国真实联合日记/偏好”“真实居民采纳率”“实测物理校准”或“训练/benchmark成绩”。这些保留为后续独立证据门，而非生成时随机填上。

生产检查覆盖全部1000户；物理验证维持先原50户，不启动全量。采集前必须用原前端试读，核演员是否理解角色、需求、后果；比较完整角色信息与删减信息是否影响独立回答/解释，允许无效或反向结果。由真实回答形成Y后，才作共享模型的分组留出、校准和低总反馈预算比较。源模式/同骨架依赖要分组；具体个人偏好不得用规则预填成训练或测试标签。

[Blum等2021的BOPTEST方法](https://bies.lbl.gov/publications/building-optimization-testing)为共同参考模型、边界、基线控制及可重复指标提供方法依据。本项目据此明确参考世界内的比较对象；该方法引用不验证我们的空调曲线、住房或真人回应。
