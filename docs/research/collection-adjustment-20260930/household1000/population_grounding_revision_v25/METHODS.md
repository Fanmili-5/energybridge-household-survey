# 六类EB的真实家庭占比：生成前估计方案（V25）

当前问题是估计中国城市家庭中六类能源协商政策的占比，而不是复现EB分配给演员的角色人数。V24的166/198/125/151/156/204只保留为历史实验构成，不再约束当前生产。真实占比与1000户整数配额均未确定；新版生成和EP保持关闭。

## 1. 先明确要估计什么

目标仍为中国大陆“市”的普通住宅家庭户，排除镇、乡村、集体户及非普通住宅。调查单位、推断权重、生成单位均为家庭户。预先确定一户一位合适的能源安排代表及其权限，保留其他成员的服务和照护约束；不能把个人样本权重直接当家庭权重，也不能删去无成年常住人的家庭来便利分类。

人口住房构成目前锚定2020年。偏好调查年份尚未冻结。若使用当期自答、2020年家庭构成作标准化，结论必须写成“按2020家庭构成标准化的当期陈述偏好占比”，不能称当期全国精确真值。旧年份的设备、偏好、政策环境须单独评估可迁移性。

EB六类是给定的种子角色，不是已被发现的中国自然聚类。A与D即使人口、职业、住房完全相同，也可能因“每次先建议”与“允许边界内自动控制”而归入不同类型。六类映射的定义、边界及家庭适配须在估计比例前确定；实际自答若大量无法对应，就应修订模板或报告适用范围，不能强制聚成六组来证明真实。

## 2. 现有证据能支持到哪里

|---|---|---|

继续优先找能在同一家庭联立测量关键偏好的数据。分别来自不同调查的边际比例不可直接相乘；统计匹配须声明无法观测的联合关系，并做可识别性和敏感性分析。数据申请或联系研究者须另有授权；本版未发送联系、未征集答卷、未转移或公开受限原始数据。

## 3. 补全偏好的可执行路线

若现有全国调查不能联立识别六类，复用原前端的真实家庭自答模式，先收本人家庭的回答，再进入角色扮演。不能用扮演后的回答反推本人偏好。

先试读并核查问题语义：在相同事件长度、补偿和安全条件下回答舒适容忍、服务时间窗口、控制权限、费用/舒适/电网取舍、规律与照护、EV及在家充电可用性。已有重要性分数可以同时很高，不能直接解释为互斥优先级；需以原问题及少量标准化情景验证取舍。居家、通勤、照护等是事实与活动情景，不能替代偏好。

尽量从有覆盖的家庭抽样框分层抽样，记录城市/气候区、家庭结构、住房、经济条件及设备资格，设计一户一次的访问与非应答记录。分类开发样本和比例估计样本应分开或交叉拟合；冻结规则后才估计占比。保留“未知、混合、无法对应”质量，不按六类等额招募后再把招募配额称自然比例。无代表性抽样框时，应如实称便利样本或模型校准估计，不能宣称加权就消除了自选择偏差。

## 4. 估计比例，并给出不确定性

固定映射有效时，先用设计权重，再调整非应答，最后按可获得的家庭户总体信息校准。对于类型k：

`pi_hat[k] = sum_i w_i * I(type_i == k) / sum_i w_i`。

分母为目标家庭样本，未知质量须同时报告；禁止只保留可分类者并悄悄归一化为全国比例。若使用软归属概率，须有经过验证的分类模型，不可使用LLM自报概率充当观测。对不完全识别的比例可给上下界和不同联合关系假设的敏感性结果，不能凭边际指标填一个点值。

按真实抽样层、初级抽样单元及重复权重估计区间，并单独评估分类误差、非应答、权重截断和年份迁移。若使用多层回归与后分层（MRP），必须先有真实偏好回答和对应家庭总体分层人数；它可缓解稀疏格问题，但不能创造未测偏好。非概率样本的模型区间不能称设计型抽样误差。不能用全体人口的年龄/性别分布校准家庭决策代表的分布。

## 5. 比例必须先于1000户生产

验收并冻结目标群体/年份、真实样本与许可、问卷/编码、映射、权重、六类比例及区间、未知质量和预设容差。之后才将比例换算为1000户整数配额，联立人口、住房、设备资格及家庭协商政策生成。不能为了填满某类额外制造EV、删家庭或篡改年龄。

正常A、服务需求、协商B及IDF均从同户政策与事实推演；保留不满足需求的B供演员评价，不自动贴接受或拒绝标签。先在原50户验证语义传递和不读类型代码的特征恢复，再验收1000户。六类恢复证明生成器遵守模板；真实占比的证据必须来自独立真实家庭数据。所有验收通过后再审查学校EP准入。

少见类型可另设平衡/压力测试视图，和真实占比主队列分开报告。每户4–6类设备仍是覆盖设计，不能冒充设备自然拥有率；若要扩大到全部城市普通家庭，必须量化此设计对适用域及偏好占比的影响。

## 6. 本版审查结论

方法路线有依据，真实六类占比尚未识别，生产资格未通过。现有来源补得了部分结构与偏好指标，但缺同户控制授权、可接受服务变化等联合测量；也缺已冻结的家庭抽样权重和经过验证的六类映射。不能用“聚类能分成六组”或历史50户物理跑通替代这些证据。原始V23/V24文件与世界保持历史状态。

依据与查阅边界见[SOURCE_LEDGER.json](SOURCE_LEDGER.json)。EB官方的“真实用户自答→估计比例→角色扮演校准”是协议依据，并非已存在的中国比例数据。
