# V27：六类进入家庭产线，原50户验收与1000户研究配比

2026-10-14。目标仍是供真人扮演、训练一个共享角色回应模型的1000个中国城市家庭任务世界。镇、乡村、集体户和非普通住宅排除；每户保留原十个抽样日期及08:00至次日08:00的完整观察日。研究检查EB六类任务覆盖；六类自然偏好比例没有得到识别。

## 已完成与未完成

新版沿用原50户、原147名成员、原住房/天气/日期及原EB设备参数；生成500组A/B、1000份静态IDF和同版本原前端材料。在学校完成1400个唯一家庭仿真运行、独立SQL回读、500页面实际浏览器验收以及接受门反例检查。这里只验收参考世界的结构、语义、执行、物理接口和页面一致性；真人回答仍为0，未证明人类角色有效性、全国偏好代表性或住宅实测校准。

在原50户通过后，对源1000户的每个可行类型进行内存中的十日期正常A/装取/交付检查，再冻结逐户分配。正式1000户的新世界、10000组A/B、20000份IDF尚未生成；整体实际特征覆盖仍待验收。1000户全量EP持续关闭。

学校本轮材料是原成熟前端的独立新版验收包，问法、布局、答卷合同均保留。旧公开在线站点没有被本轮替换；不能把它显示的历史版本说成新版已部署。

## 生产逻辑

1. **保留源家庭骨架。** 七普城市普通住宅的省级、代数和自然间控制约束合成骨架；CHFS作为同户成员关系、粗年龄、工作等辅助。源字段保留unknown，不按缺失就业分派真实职业。住房是匹配住宅参考原型，H7不是卧室数。
2. **先匹配类型条件。** A/D要求有适龄且源代理支持工作的成人；F再要求既有给定EV功能。B要求成人责任人；C允许成人或原已明示的非同住成人监护人。E要求成人与另一位幼儿/老人候选，再明确给定具体保护服务。年龄仅支持情景候选，不能推出疾病、依赖、响应低或控制态度。75岁以上已知工作者仍采用明确的短时参考活动，未知就业不写work。
3. **固定一户政策。** 确定负责人员、通常温控、临时变更幅度和时长、任务移动范围、费用/解释取舍、自动权限、确认规则、保护服务。政策十日期不变；源舒适重要度、额外家务意愿和人类采纳仍为null。未知源偏好与明确给定扮演政策分别保存。
4. **形成日期化日程与服务。** 日期、年龄、学习/工作证据、具体照护、同户共享空间决定日程。C有日期变化；E的两次共同在场检查真实占用可用时间；F读取给定驾驶/接入及出行合同。人在家不等于有空，儿童洗浴助手在原日程上联合预约，不能覆盖工作/睡眠。学校/日托及钟点是参考情景，不能称全国联合日记分布。
5. **先需求，后正常A。** 库存释放、服务数量、洗浴/出行和交付期限独立于A。洗衣库存08:00释放，装取按实际可用窗口预约，前一批程序与取出完成后才能开始下一批。A须满足共同服务和操作约束。
6. **冻结A，再生成多种B。** 正常A、需求、硬件与初始化绑定后，生成近边界、不便但可做、联动、协商、约束挑战与服务风险。缺乏该机制条件时记录不可用及实际机制，不能虚称均衡。坏B保留；规则/授权/物理标记不是演员拒绝标签。
7. **同一账本进IDF与采集材料。** 占用、人员/照明、实际装取/程序、空调、热水和EV状态来自同一世界及连续执行账本。IDF、SQL、角色卡、任务页面和模型输入都有内容绑定。授权/费用进入语义，不能任意改变硬件功率/COP/曲线来制造类型负荷差异。
8. **从具体输出核覆盖。** 特征读取实际日期化作息、具体服务及明示政策。先对应共同EB语义，再用不读标签的成熟Gower/PAM检查。类型代码、家庭编号、模板名、示例答案、真人答案及EP结果不作聚类特征。覆盖通过仅说明给定情景得到实现。
9. **冻结后另验收全量静态输入。** 1000户分配固定原50户已经验收的政策；全量生成不得重抽该子集。新1000户仍须逐户源结构/字段/服务/A/B/IDF检查和实际整体覆盖审查。只有下一阶段完整验收后才讨论全量EP准入。

## 1000户配比冻结

主配置：**A101/B303/C319/D101/E85/F91**，即10.1%/30.3%/31.9%/10.1%/8.5%/9.1%。

每户在源结构支持且十日期正常服务可执行的类型中构造均匀q；按既有省级普通住宅家庭户校准权重形成参考期望：省普通住宅户数/省整数配额/全国普通住宅户数×1000，整批权重和为1000；这是家庭户结构权重，非个人权重或真人调查权重。q不是观察到的偏好概率。保持所有1000户，六类至少各50户作为覆盖设定，并固定原50户政策。联合检查全部63个类型子集容量，再用HiGHS小整数问题求最接近期望的配比、HiGHS最小费用二分分配落实到逐户。两步都必须status0；第一次大MILP超时结果未接受。家庭事实不为配比改动。

正常A候选容量A530/B984/C998/D530/E363/F489，相互重叠，不能归一化当比例。4户各有一个候选的EV接线操作不可执行：C2、F2；保留失败并从其他实际可行类型分配。没有无法归类家庭或删户。仅在内存检验条件/正常A，不代表已验收1000户完整B/IDF或实际聚类。

将A/D可行总质量中的自动授权比例改成0.2/0.5/0.8，敏感性另列冻结报告。它证明缺乏授权证据会影响配比，不是置信区间。主配置0.5有意作为未测分割设计，不是“中国一半家庭自动授权”。各类最低50只是研究覆盖，对A/D极端分割有下限修正，必须随结果披露。

完整证据见[PILOT_ACCEPTANCE_SUMMARY.json](PILOT_ACCEPTANCE_SUMMARY.json)、[FROZEN_COMPOSITION_SUMMARY.json](FROZEN_COMPOSITION_SUMMARY.json)、[PHYSICS50_SUMMARY.json](PHYSICS50_SUMMARY.json)。逐户分配、世界、IDF、SQL和真人记录不在公开仓库。公开仓库提供源码、方法、原前端空模板与聚合证据，单凭公开仓库不能复现受许可保护的输入。
