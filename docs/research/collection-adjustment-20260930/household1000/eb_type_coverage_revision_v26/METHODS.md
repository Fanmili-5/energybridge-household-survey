# 1000户与EB六类的类型覆盖一致性（V26）

2026-10-14，用户明确学长提出聚类的目的为“类型覆盖与EB一致”。本版据此修正当前生成前置要求。V25的全国六类偏好比例估计不再是本任务生产门槛；V24的演员人数配额也不重新启用。两版历史记录保留，不修改历史世界或物理结果。

## 1. 聚类要回答的问题

这1000个家庭任务世界，是否覆盖EB六类所要考察的不同能源协商情景？各类是否在具体作息、舒适边界、任务时间窗口、费用取舍、控制权限和可用服务资源上体现出相应特征，而非只改角色名字？哪一类缺失、被重复模板淹没、或在家庭条件下不成立？分析结果应反过来约束生成规则。

这是有参照的类型覆盖检查。聚类不是全国人口比例估计；强制设k=6不是覆盖成立的证据；给1000户附六种标签也不能通过。聚类也不充当共享角色回应模型的路由器，不能据此改成六个模型或每户一个模型。

## 2. 参照定义与家庭适配

唯一类型参照为固定作者提交2b17ae63e613da776c93e900f5dace50d63a88a8的六个basic_role原型。它们依次覆盖：A通勤费用优先且先建议；B居家舒适优先且逐次确认；C作息易变且谨慎确认；D规律通勤且边界内自动优化；E照护安全优先且提醒为主；F通勤EV服务与自动错峰。六个种子角色、五类多成员家庭场景和六种设备是三个不同对象。

保持中国大陆市级普通住宅家庭户的源人口/住房约束，排除镇和乡村。六类在本项目适配为家庭任务政策及相关责任人的情景，其他成员的睡眠、学习、照护和服务需求逐人保留。人口或设备字段不足以推出本人偏好；研究中给定的角色取舍和权限明确标为设计条件并向演员展示。无需先采全国心理偏好比例才能构造这种角色任务世界；后续真人试读与反馈仍是独立的人类有效性证据。

不机械复制单人原型的全日时间或设备数量。每户仍覆盖4–6类EB功能设备，使用既定物理模型；增加一类设备不自动改变权限。F需要有依据或明确标注的EV服务与接入情景，E需要具体照护安排，未知就业不能写成已知职业。原型scoring_weights、vpp_override_prob及例子回答不能作为真人接受标签或聚类特征。

## 3. 先建立共同特征与生成约束

对EB参照与生成家庭采用同一字段口径，分六组，见FEATURE_AND_CLUSTER_CONTRACT.json。字段直接来自日期化作息、明确给定的协商协议、具体服务窗口及资源约束。家庭人数、气候和设备总数用于源结构/适用域审计，不能靠这些字段代替EB所区分的费用和权限特征。

先冻结每类的核心条件、组内允许变化、跨成员冲突规则及证据身份，再联立家庭骨架、住房和设备资格检查可行性。给定偏好需向正常A、可协商边界和多种B传递。不能为凑类型删除源家庭、篡改年龄、把外部帮手计为居民，或制造未标注的设备所有权。V24的984/49容量来自旧年龄适配规则和旧配额，不能作为本版可行性证明。

类型人数是任务覆盖设计。先在原50户检查家庭适配、规则可行性和各类内部差异，再在1000户生产前冻结每类的最低覆盖、正式人数或区间、分层分配规则及验收阈值。当前没有已批准的数值。不得直接复用584名演员的构成，也不得把设计构成说成中国自然占比。人口/住房源分布和类型覆盖构成分别审计，不能为偏好配额扭曲源结构。

## 4. 两种互补的验证

**语义与参照映射。** 从完整任务世界重新提取事实，检查每类核心条件的证据及落地情况。按冻结的参照和共同特征做对应，报告六类覆盖数量、代表家庭、组内变化、距离和混淆。关键缺失、冲突或跨类模糊保留为缺失/模糊，不能一律最近邻硬分。类别标签和生成分配表仅在事实提取完成后用于核对。

**不读类别的聚类。** 只输入上述共同特征，对1000户做混合变量聚类，比较数据结构与EB参照。R cluster::daisy的Gower距离与cluster::pam作为候选；字段权重、尺度、缺失处理、初始化及软件版本须在正式生成前冻结。daisy默认数值尺度来自当前数据范围，固定范围的研究实现须单独说明与验证，不能把自定义处理冒充软件默认。

簇与参照的对齐根据特征和核心条件完成，不能把簇编号直接当A–F。参照映射与聚类结果分开报告。核查合并/拆分、每类遗漏、跨类重叠、重采样稳定性、字段权重敏感性及重复家庭；k=4..8可作结构诊断。k=6只表达本研究希望覆盖六种参照情景，不能被解释为中国存在六个自然群体。若A/D等核心差异只写在说明中而未进入具体权限和任务后果，应修正生成逻辑；若核心差异存在而当前距离方法分不开，应审查特征和度量，不能事后挑种子或添加标签让结果通过。

## 5. 验收与顺序

核心验收是：六类都有实质覆盖、同户语义无冲突、差异传到作息/服务/正常A与协商B、类型并非编号或答案泄漏造成、组内有合理变化，且覆盖结论对合理分析选择稳健。数值阈值是本研究预设质量要求，需在原50户开发后、正式1000户生成前冻结；不沿用未验证的V24阈值当权威标准。

顺序：**EB六类定义 → 共同特征与家庭适配 → 联立源结构、设备和覆盖可行性 → 明确给定政策 → 作息/服务与正常A、多种B → IDF → 原50户覆盖及既有物理/前端验收 → 冻结生产规则、构成与阈值 → 1000户完整输入及覆盖验收 → 再审查学校全量EP准入**。

保留坏B供真人评价。物理成功、六类覆盖和真人回应是不同层的证据；不要把任一层测试通过推广为其他层成立。类型覆盖不替代前述六项生产缺口、原50户物理验收或真人有效性工作。
