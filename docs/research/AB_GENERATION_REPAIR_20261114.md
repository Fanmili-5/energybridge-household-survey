# A/B生成修正与实际验收（2026-11-14）

**1000户×10题的新计划已生成并封存；完成20000次原版A/B电器执行回放。两组新配对物理试例通过，一个UI91隔离预览通过。全量物理后果、覆盖尾项和正式真人采集尚未完成，不能作为已标注训练集发布。**

## 修正了什么

- A由家庭参考周驱动，用CP-SAT联合排完整程序。洗碗绑定已完成的一餐，同批衣物先洗后烘，热水器围绕洗浴，EV保持停车连接内连续充电；不为VPP效果重抽A。
- B按官方paper-v1-final的六类原动作枚举，用IPOG-C和CP-SAT寻找完整候选；选题由SciPy/HiGHS整数规划完成，每日只保留一个B。原版实际检查时点由冻结family_runner相关AST执行，替代后来V2/V3包装限制。
- 空调偏好与动作范围分开：全局22—28℃、一位小数，制热保持20℃。偏好冲突、预计效果差或可能被拒绝不作删除条件。未知热效应不算零。
- 程序设备不切碎、不改时长/功率；不新增停冷、独立制热或手工装取。连续EV、每日完整任务及仅EV可跨夜是本批明确的实验选择。
- IDF适配补回热水器窗口：窗内执行目标温度，窗外采用已有绑定支持的内部关闭编码；继续模拟真实水箱蓄热、损失和用水，不伪造电量。这个内部编码不是新增Agent动作。

A为有调查与生活规则依据的实验参考日程；原型资源窗口不冒称实测电机工作时长。B是待居民判断的完整反事实提案，不等于已获家庭同意的原Agent完整LLM轨迹。
