## 已验证与待验证

| 层次 | 已有证据 | 边界 |
|---|---|---|
| 源与接口 | 内容锁、A侧等价、身份/权限及计划校验 | 检查过的批次不等于任意新输入都通过 |
| 选题与覆盖 | 设备关联、归一化覆盖、重复惩罚、长尾及缺额报告 | 不证明穷尽全部组合，不把覆盖比例解释为自然发生频率 |
| 物理与显示 | 同版本A/B、原生回读、零未知准入和UI91资料绑定 | 参考模型估算，不是实测账单、室温或住宅认证 |
| 采集 | 独立版本库、跨轮身份、草稿、恢复、撤回与修订协议 | 工程测试不计为真人标签，匿名身份不证明自然人唯一 |
| 研究有效性 | 信息边界与分组原则已有说明 | 真人理解、标签质控、最终划分/指标及模型成绩仍需实际完成 |
