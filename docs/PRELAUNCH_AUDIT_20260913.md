## 正式分发前仍须完成

1. **真实试填**：先做经授权的真实模型小试，再让少量非开发者完成问卷，记录等待时间、失败率、回退比例及题意误解。没有这项证据，不能承诺 50 人同时生成时的体验。
2. **正式库切换**：建立全新数据目录并以 `--human-pilot` 启动，核对普通参与者来源标签；保持工程库原样。当前地址仍是工程演示入口。
3. **持续异地备份**：将现有小时快照自动保存到另一台机器/对象存储，并保留恢复验证。单机快照和一次临时下载不足以覆盖整机丢失。
4. **分发与费用额度**：当前 250/日是费用限制，不是并发能力；按邀请节奏和真实 API 账单调整。会话限次不能证明唯一家庭，正式数据分析仍要做去重。

本轮修复后的工程放行不保证问卷研究效果或模型规划质量，也不把未执行的真实测试写成已通过。
