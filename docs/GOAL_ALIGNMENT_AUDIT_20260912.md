# 任务目的与完整性复核

> 历史审计快照：下文包含已替换的四天、固定住宅和旧评价范围。当前采集主线及上线结论以 [最终上线前审计](PRELAUNCH_AUDIT_20260912.md) 为准；训练、评测和模型回接不属于本项目上线条件。

结论：现有主线适合收集“家庭代表看完模拟方案对比后的判断”，但从问卷采集到 SFT 模型替代 EB 评价的完整研究链路尚未完成。不能把已有工程测试通过当作训练或部署有效性证明。

## 不变的目的

真实家庭事实、成员情况与态度 → 原安排及同情境 EB/EP 调整轨迹 → 真人 accept/reject、四项独立评分、可选原因 → SFT 学习家庭判断 → 在同样的信息条件下替代家庭层面的模拟评价。

不训练 EB 的规划推理，不以程序规则或模型代打分。一个人代述成员资料并给出家庭判断，不构造成多位成员独立评价，也不归入五个预设家庭。

## 核对结果

| 环节 | 已有实现 | 判断与剩余工作 |
|---|---|---|
| 家庭资料 | 原回答、规范值、题表快照、成员资料、扩展信息独立保存 | 符合一次采集兼顾后续研究的目标，无需全部强制进入规划 |
| EB 输入 | 设备与时间进入执行配置；成员和态度进入可见上下文；研究字段另存 | 符合分工。进入提示词不等于每个字段都确定性改变策略，不能这样宣称 |
| 原安排 | 问卷习惯经原 EB ordinary/manual_no_vpp 路径生成控制，再跑 EP | EP 负责计算结果，不是凭空选择日常安排 |
| 调整方案 | 同住宅、天气和前缀状态；EB 随模拟状态规划；原生检查、修正、执行器 | 主路径成立；原生执行拒绝与回退需要保留并在审计中区分 |
| 真人评价 | 实际轨迹、模拟结果、任务结果；二元选择、四个小数评分、可选原因 | 标签是对所展示整套安排的家庭代表判断，不是每轮决策、每位成员或真实控制结果的标签 |
| SFT 输入与目标 | `candidate()` 输入 household_answers 与 participant_view，目标来自 decision.json | 方向正确；EB 原始推理不充当真人理由，缺失原因不补造 |
| 训练发布 | 候选导出区分版本、真人/工程来源，保持 training_release=false | 尚无正式发布审核、划分与模型验证流程 |
| 替换 EB 评价 | 上游有 post_event_score_callback 扩展入口 | 当前仓库尚未实现问卷训练格式到该入口的完整适配和验证 |

## 正式采集前应落实

1. **冻结模型的评价范围。** 当前数据是完整比较期的方案判断；继续保留这个范围最符合已确认的需求。不要把一个最终评分复制到 EB 每次重规划上。
2. **确定回接时刻与输入。** 固定上游的 `_event_score_due_hour` 在事件当天 24:00 触发评分；问卷的共同终点可能在次日。建议第一版在完整比较期结束后评整套方案，并由统一输入构造器向真人页面与 SFT 模型提供同一组语义信息。若坚持原 EB 当天评分，需另行对齐采集窗口，不能使用当时尚不可见的次日结果。
3. **明确输出接口。** `decision=accept/reject` 与原 scorer 的满意度 `label` 是不同字段。小数分保留；成员评分缺失就不生成；新增 SFT 来源明确记录，不能冒充原角色评分器。原生评分入口还有来源检查，不能仅换模型地址就认为完成接入。
4. **完成受邀真人试采配置。** 工程/管理员测试不能进入正式标签集。切换前先完成一次新版真实生成、查看对比、提交小数评分、持久保存、默认导出全过程；不能只验前端 mock 或 EP fixture。
5. **解决家庭分组标识。** 当前 household_id 来自浏览器会话，换浏览器会变。建议招募环节提供匿名研究编号，用于同家庭关联与数据划分；它不需要是登录账号，也不需要姓名或标明哪位成员填写。

## 数据发布与训练前补齐

- 把正常模型方案、部分执行拒绝、控制器回退分别统计；不因真人拒绝或评分低就删除样本，也不把所有回退都称为 EB 模型策略。
- 只把有真实反馈的样本用于对应监督目标；计算失败但已保存的家庭资料可用于画像研究，不能伪造监督标签。
- 按家庭分组划分训练/验证/测试，同一家庭的不同案例不能随机散落。会话 ID 本身不证明家庭唯一性。
- 先检查设备组合、可调空间、方案变化、接受/拒绝、评分及原因缺失的分布，再决定补充什么情境；不人为凑出拒绝标签或强制 EB 改动。
- 当前天津 7 月 4 日、固定住宅、电价 0.60 元/度、零补偿、有限傍晚事件，可支撑限定情境的研究，不能代表全国、四季或各种价格激励。扩展不是开始试采的前提，但泛化结论必须受此限制。
- 基础模型与 SFT 模型在独立家庭上比较决策预测和四项评分误差，之后才评估代替 EB 家庭评价的效果。单次整套评价没有监督出多成员讨论或长期偏好演化能力。
