# 电器逐项对比与跨夜仿真

本次修正两件事：同一电器的调整前后紧邻显示；午夜以后的运行进入真实 EP 仿真和结果统计。

| 环节 | 当前规则 |
|---|---|
| 问卷 | 输入字段与十分钟时间选项保持不变。 |
| 比较范围 | 提交后、规划前固定：当日 00:00 至次日 06:00；若填报的跨夜任务截止时间、空调使用结束或 EV 离家更晚，延长到其中最晚时刻。 |
| VPP | 仍在第一天抽取一次 1 或 2 小时事件。延长观察不额外制造第二次 VPP。 |
| 执行 | 两条原生策略使用相同住宅、天气、价格和截止时刻。准备覆盖两天的 RunPeriod，通过 EP 回调在指定十分钟边界正常结束。继续原有日常控制，不补写预设节电策略。 |
| EB 边界 | 原文件不变；原规划回调 AST 校验保持一致。衔接层提供共同总时长、正常结束回调，以及跨年连续时钟。真人评价仍待填写，不生成代理评分或更新偏好记忆。 |
| 电量与费用 | 两者都统计到共同截止时刻，并核对原生价格计算使用的电量与 EP 电表积分一致。字段 daily_kwh / daily_cost_normalized 保留兼容，界面明确标为“比较时段”。 |
| 完成情况 | 洗衣等检查第一天任务在截止时刻的执行状态，排除末次回调预计算的下一时段；EV 记录离家前、扣除驾驶耗电前的 SOC，截止时刻恰好离家也计入。水箱温度仍只表示水箱温度。 |
| 展示 | 一个电器一个分组，上方调整前、下方调整后，共用横轴；默认完整时段，另可放大。指标表紧随其后。研究验证状态保存在审计数据中。 |
| 历史记录 | 不延长或重算已保存的 24 小时结果；v3.5 的原有四项评分仍可填写。新记录使用 paired v3.6、UI v6.11、执行边界 v4。 |

一次示例的 EV 次日 08:00 离家，比较范围就是 32 小时，而不是四天或完整 48 小时。常规日及 12 月 31 日跨年原生无模型基线均已取得 192 条十分钟电表记录，次日用电进入总量；两份策略的原生技术回退仍可保留为待真人评价的数据。

这不是“完成同等服务后的纯节能”实验：图中两条策略可能有不同的任务完成情况，次日继续遵循原有日常控制。参与者依据实际展示的安排、用电和服务状态给出是否同意、四项分数和原因。

验证记录见配套 JSON。测试使用固定模型回复与真实 EnergyPlus，不产生付费模型调用；工程样例不作为真人样本。

- 原有 3 个任务、21 份文档、2 份家庭资料与停服备份逐项一致。仍为 engineering 模式，没有将测试记录改标为真人正式样本。
