# 采集与质控

正式入口使用UI91精简展示，保留v69字段和存储协议，评分改为0—5分方块单选。参与者扮演给定家庭，依据本题A/B与实际可见的参考后果独立评价，客观VPP结果不预设评分或接受答案。版本见[数据与验收](DATASET.md)。

## 分户与作答

1. 自愿阅读说明后开始，家庭由系统分配；每轮固定一户10题，未完成恢复原进度。完成且没有未提交修改后，可自愿领取另一户，同一身份不重复领同户。
2. 四项评分均为0—5分整数，每项点击一个方块；默认未选，0分与未作答区分；接受/拒绝及具体原因必填，没有默认答案。评分针对给定家庭的响应安排、舒适生活、用电费用和VPP配合。
3. 控制设定和模型室温分开展示。每题使用同版本物理估算；旧提案示例的未计算状态单独标注，不能填0或借用旧B结果。
4. 本版删除“查看完整资料”入口；洗衣与烘干分开展示，不显示装载、取出和工程诊断。旧版排程查看记录仍留在旧库，新版不补入隐藏资料。

## 保存、恢复与分析单位

- 每份回答绑定发布、家庭、案例、页面、可见信息及修订号。重复提交幂等，修改追加修订；旧版本不重标为新版本。
- 同一`participant_id`及恢复码跨轮保持，每轮另有`assignment_id`。领取下一户不会把同一个人变成新的独立参与者。
- 恢复、重启/备份、旧页面写入隔离及全轮撤回按[采集器协议](../benchmark/collector/README.md)执行。
- 分配不使用评分、接受判断或仿真成败。匿名cookie和恢复码不证明自然人唯一，招募与重复身份核对另有私有台账。

## 标签质控

分别统计已开始、完整轮次、最新提交、人工复核有效数和每案例缺口。复核追加保存规则版本、审核人、理由及回答修订；回答改变后旧复核结论不自动沿用。

工程测试、撤回、未同意、非最终修订、版本错配或必填缺失不进入有效标签。过快、复制或无关理由是人工复核线索；同分、短理由、始终接受/拒绝或与客观结果不一致不能单独作为剔除依据。真实分歧保留。

正式采集需要题意理解检查及冻结的质控规则。人数、重复评价和抽查工作量须另行登记，不把方案数字当成已完成或统计最优。工程测试不计为有效真人标签。

管理导出以当前修订、同意及撤回状态为准；`--quality valid`只取已人工复核有效的记录。数据库、查看历史、复核与原始恢复材料须一致备份。划分和不确定性分析同时考虑家庭及跨轮参与者，见[评测协议](EVALUATION.md)。
