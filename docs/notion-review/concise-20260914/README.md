## 1. 问卷内容
每户由一人填写家庭情况和成员偏好，EB据此规划。
结果出来后，由同一人代表家庭选择、评分。
### 字段对应表
回答保存在 `raw_answers`，`[i]` 表示第几位成员。
“后续分析”项只保存，暂不参与EB规划或EP仿真。

## 2. 提交后怎么生成方案
### 日期与天气
- 填写前，从全年365天等概率抽一天；同一浏览器会话刷新不重抽。
- 用户按抽中的月份填写习惯。2007仅作非闰年日历，实际读取站点典型年天气。
- 按所填省市找同城站；没有则用预设省内代表站，例如广东用广州，不按距离选站。
- EP读取抽中日期的天气；跨日仿真继续读取后一天。
可用天气文件246份，覆盖34个省级地区，来自OneBuilding：
- CSWD：214份。
- TMYx.2011–2025：25份；其他TMYx：7份。
- 另有92条不可用记录，匹配时跳过。
[查看天气文件目录](https://github.com/Fanmili-5/energybridge-household-survey/blob/main/simulation_resources/catalog.json)
### 建筑
按住宅类型、楼层、面积区间和面积口径，从50个已验证原型中选择。
- 五档面积取40、70、105、140、180㎡。
- 填建筑面积时，乘0.8换算为室内面积。
- 材料和设备沿用作者模型，替换站点位置、设计日和地温。
这是住房近似模型。供暖固定20℃，空调调整主要控制制冷；日期可以覆盖全年。
### VPP与电价
- 开始时间：17:00、18:00、19:00，等概率抽取。
- 持续时间：1或2小时，等概率抽取。
- 电价：统一使用EB天津归一化分时权重，成本为相对值，不是人民币电费。
### 两份安排
问卷答案转为家庭JSON和电器原日程后：
1. EP运行原日程，得到调整前的用电和室温。
2. EB根据家庭需求、VPP和模拟状态调整计划，再由EP执行。
保留原EB的技术检查、回退和后续规划。是否接受、怎么评分，由真人回答。
两路使用相同日期、天气、建筑和事件。匹配或仿真失败时，问卷仍保留，暂不展示结果。
### 统计时段
比较表固定统计24小时：
- 有EV：离家时刻至次日同刻。
- 无EV：当天00\:00至次日00\:00。
EP从当天00:00开始，步长10分钟，按完整日覆盖统计终点和所填任务期限，实际运行1或2天。
例如离家08:00：EP跑两天，比较表只统计当天08\:00至次日08\:00。
时间轴可显示统计范围外的运行。其他电器仍可能跨过这24小时的边界。
## 3. 用户看到什么，怎么评价
验证码通过后进入等待页，完成后自动显示结果。
同一电器的调整前后安排放在一起，标出起止时间和“次日”。对比表列出用电量、成本、室温和任务完成情况。
用户填写：
- 同意或不同意。
- 四项评分：整体、舒适、用电费用、安排调整与自主体验，可填小数。
- 主要原因。
![结果页示例。这次测试触发了回退，部分任务没有执行。](../readable-20260914/result-timeline.png)
