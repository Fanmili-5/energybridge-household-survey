验收使用合成家庭和模型桩，不支付模型费用。主线代码未加入自定义偏好门槛或新规划规则。旧版四天执行代码只服务历史回归；当前入口是 `native_worker` 的一天 `no_dr/agent` 比较。

测试工具：
- `scripts/test_offline.py`：后端、原生接口、全年抽样与存储回归；指定 `EB_TEST_NATIVE_EP=1` 后运行实际 EP 检查。
- `scripts/build_intake_review_sample.py --out <新的私有目录>`：完整提交、真实 EP、合成标签、完整导出及关联校验；目录含会话和原始记录，仅供内部审核。
- `scripts/test_frontend.py`：真实本地 HTTP/SQLite/EP 链路，390px 与 1365px；日期、草稿、省市联动、六页填写、时间轴、小数反馈、刷新恢复。模型调用用离线桩。
- 两份旧记录显示兼容回归保留在 CI；其他 2026-09-11 浏览器审计脚本记录当时问卷版本，不能替代当前整链路测试。
- `scripts/check_secrets.py --history`：审核索引及可达历史的凭据特征；不是对所有可能敏感内容的绝对保证。真人数据和运行日志均不在发布包内。

数据边界：`household_id` 是浏览器会话代理，不声称已验证为唯一家庭；跨浏览器去重由招募与数据接收流程处理。全年日期采用典型年；住宅为研究近似，供暖沿用原 EB 参数，跨午夜服务只报告本比较日可观察的结果。演示记录和真人记录不能混用。

仓库公开、离线测试通过并不等于承诺真实 API 永不超时。实际招募前用小批真人试填检查等待时间和问题理解；这属于数据采集试运行，不要求先训练模型。

当前 GitHub CI 验收结果：174 项后端测试全部通过（Python 3.11、EnergyPlus 24.1）；390px 与 1365px 各完成一条 HTTP→SQLite→原生 EP→小数评价与必填原因链路；展示、错误恢复和资源恢复检查通过。以上均未调用付费模型 API。CI：`https://github.com/Fanmili-5/energybridge-household-survey/actions/runs/34692755379`。
