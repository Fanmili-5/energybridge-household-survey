# 时间轴日期与起止时间修订

问题：原图需要点击色条才能看到精确起止时间，滚动到后面的电器又看不到顶端日期刻度。当日凌晨和次日凌晨缺少明显区别。

修改：

- 同一电器仍为上下两条调整前后时间轴；每个电器重复日期和时间刻度。
- 当天、次日使用不同底色，以午夜分界线分开；坐标一直使用累计小时，不把次日时间取模放回左边。
- 图下常显“时段（开始 → 结束） / 调整前 / 调整后”表。午夜显示“次日 00:00”，跨天充电显示如“当天 22:00 → 次日 01:50”。
- 连续运行中的功率变化合并为一个可读运行时段；温度设定的变化保留。原始色条和点击详情仍保留细分功率记录。
- 表中按两份安排的共同时间边界逐行比较；双方均未运行的间隔不额外列出。空白色条仍表示未运行。未更改任何模拟记录、问卷字段、规划策略或能源指标。

示例本身确有两次充电：当天 00:10—04:00，以及当天 22:00—次日 01:50。前者不会被移到次日；这是两段不同的模拟记录。
