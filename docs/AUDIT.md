# 发布前审计记录

目标保持为：真人家庭信息 → EB 配置与规划 → 两份 EP 模拟结果 → 真人接受／拒绝及四项小数评分 → 家庭角色模拟器 SFT 候选。工程结果不冒充真人标签，成员代填不冒充独立投票，不强制归入五类预设。

本轮修复：

| 问题 | 最终处理 |
|---|---|
| 资料保存依赖创建计算任务 | 独立不可变 household intake；暂停、失败和未评价资料仍可导出 |
| 刷新及异步反馈导致草稿错配 | 新草稿优先、按案例绑定反馈回调、收据与生成分别幂等 |
| 跨午夜任务的原定时间被截断 | raw 值保留，EB 派生时刻显式换为次日并记录来源 |
| 原生热水命令与 EP 执行存在不一致 | 保存原答卷；不改写 EB 命令；已知不兼容执行不能作为完整方案进入评分 |
| 相对持久目录导致工作进程找不到输入 | 数据目录在入口规范为绝对路径，增加实际子进程读取回归 |
| 无准入预算与隐式读取模型配置 | 队列/会话/日额度；模型仅读取显式配置，默认关闭规划 |

发布目录验证：

- 105 项后端测试，包含显式开启的原生 EnergyPlus 检查，全部通过。
- 6 套浏览器离线回归全部通过；另有隔离真实 HTTP 保存与刷新恢复验证。
- 本机 50 会话固定工程策略 + 真实 EP 测试：50 份完成、50 次重复请求去重、50 份小数反馈保存；重启恢复、会话隔离与备份验证通过。EP 槽数2、任务工作线程2；不代表云服务器或真实模型性能。
- 原生 EB 版本固定并独立拉取验证；上游源码未修改。
- Git 索引扫描未检出凭据或禁止的运行产物；与本地已知配置密钥做精确匹配也未检出。仓库不提交 .env、私钥、数据库、真实答卷或调用日志。保留的 JSON 是回归用工程样例及题表。
- 本轮付费模型 API 调用为0；未修改线上部署。

仍需目标环境验收：实际域名与 HTTPS、Linux 服务配置校验、真实模型单案例端到端及云服务器排队延迟、异机备份恢复。当前住宅和天津天气是研究原型；未实现按真实住址重建建筑或随机天气。部分热水时间可以收集，但原 EB/EP 执行暂不支持生成配对结果。

数据导出始终是候选，正式训练前仍需处理重复家庭、按家庭划分测试集、核对来源和缺失标签。不得把本轮工程测试作为真人研究效果证明。
