### 必须保留的边界

1. **线上已切换正式采集。** 公网入口为 `human_pilot`，管理员入口仍为 `engineering`；历史测试记录保持原标记，默认真人导出继续排除这些记录。
2. **No-DR 不等于逐项复制用户日常时刻。** 原 EB 的 `_schedule_no_dr_routine_appliances` 会在允许窗口内随机安排洗衣、洗碗、烘干。当前接入保留该行为；时间轴来自本次实际运行。问卷说明已补明，向参与者解释“原安排”时也应避免混淆。
3. **本轮没有付费模型验收或真人并发压测。** 32 个 EP 槽位、4 个 API 槽位是配置，不是 50 人同时提交时的时延承诺。需依据后续试填的排队、模型耗时、超时率判断分发节奏。
4. **浏览器会话和昵称都不是独立人数证明。** 同一个人换浏览器可能另算；选填昵称用于核对，不能直接据此宣称独立参与者数量。
5. **默认定时备份不包含全部仿真附件。** 数据库及案例文档已有快照，完整轨迹另用完整备份；诊断下载也有文件类型和大小限制。
