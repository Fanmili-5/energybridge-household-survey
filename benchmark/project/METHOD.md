# 连接方法、依据与人工设定

本页保留六户离线接口示例及生成时的口径。当前正式50户在冻结新B后完成500组配对仿真，见[完整物理自查](FULL500_PHYSICS_VALIDATION.json)与[正式方法](UI91_FORMAL_PHYSICS.md)；后算结果不回灌B生成或改写旧答案。

本入口做接口连接，不声称提出新的家庭生成、最优化或物理算法。它复用已公开模块的输入、约束、固定种子和审查结果；与原EnergyBridge的语义继承、我们自己的实现、数值设定及未验证结论分别登记。

| 环节 | 依据与实现 | 项目设定 / 适用边界 |
|---|---|---|
| 家庭与角色 | [家庭方法](../family_generation/METHOD.md)、[六类证据](../household_archetypes/EVIDENCE.md) | 六种合成联合模板；角色是实验条件，不是人口比例、真实偏好或标签。整户生成，不按 B 成败重抽 |
| 生活 → A | [生活方法](../ab_generation/LIFE_METHOD.md)、[生活规则](../ab_generation/LIFE_RULES.json) | 先给定日历和服务需求，再用有前后关系、装取、资源不重叠的确定性排程形成A；不是宣称使用CP-SAT求全局最优。约束形式与来源中登记的OR-Tools job-shop原则对应 |
| A → B | [生成规则](../ab_generation/GENERATION_RULES.md)、[联合算法](../ab_generation/JOINT_LOAD_SUPPLY.md) | 程序链移时和原EV连接边界不变；联合目录保留冲突。网格、剂量及搜索预算是实验设定，不称为论文原值 |
| 没有热状态时 | `offline_unexecuted_A_plan`；`plan_only.py` | 只按声明的控制与占用窗口构造热探索。未知运行负载/温度/余量不补造，所有热请求为exploratory，实际响应和费用未知。与原完整A运行oracle实验严格分开 |
| 目录 → 预览样本 | [最终分层方法](../ab_generation/FINAL_SAMPLING_METHOD.md)及登记的Statistics Canada分层原则、NIST组合覆盖测量原则 | 固定分层与种子，先形成目录再一次选择；不等于人口概率抽样，也不保证全组合覆盖。六户预览不能替代旧冻结10层验收 |
| 住房与模型 | [住房方法](../housing_simulation/METHOD.md)、[来源](../housing_simulation/SOURCES.json) | 匹配参考几何、安装与热环境配置；模型编译不代表执行、校准或物理通过 |
| 问卷资料 | [原EB固定来源](../ab_generation/provenance/ORIGINAL_EB.json)、既定 `collector/answer_contract.py` 和v69源文件 | 采用现有接受/拒绝、四维评分及原因。这里只适配数据；不将原EB的其他两阶段问卷强加到已定v69，不导入其接受先验，也不声称是原控制器真实策略输出 |

文献支持建模原则，不能代替本项目取值或给定情境的验证。各模块的 SOURCES、参数注册及授权说明继续有效；本连接入口未复制原EB未确认许可的代码、角色卡全文或人类答卷。公开资料全部由本仓库合成参考池和自有代码生成。

## 信息集合

完整未来生活A是给定的离线安排，生成器可读取其完整命令和同一生活账本的解析EV充电计划；它不是实际未来观测、预测器或部署控制器。新模式禁止携带热原生运行状态；热探索不能宣称有实际可交付容量。原 `offline_full_A_counterfactual` 模式仍要求独立完整A运行参照，没有被放宽或替代。B实际后果和人类回答不能参与B生成、分层、重抽或换样。

## 此批固定参数

全部运行参数在 `examples/project.json`，模型准备参数在 `examples/preparation.json`：

- 家庭池和家庭输入按SHA固定；6户、6类角色仅用于接口检查。
- A生活日历2025-03-01至2025-08-01；比较日期2025-07-15、08:00通知、18:10—19:10向下1.5kW事件，均为项目实验情境。日历在家庭生活/B生成之前声明，用于提供模型准备所需112日前史及9日尾期，不看B结果补改。
- 电价为预先声明的实验价，单位CNY/kWh；不代表现行本地电价。问卷没有实际账单结果，也不把局部解析预测变成全屋账单。
- 程序移时±120分钟、10分钟网格（24非零剂量），热剂量/时长沿用原规则；联合预算8192，未限定只能两类。是有限预算目录，不是所有可能排程的穷举。
- 种子20261019，8个预览分层，每层申请6户×1案，仅原样对照层为必需；设备/机会不足的可选层缺额保留。配置不保证必有每个设备或B成功。
- 配对模型使用公开Chicago TMY3气象SHA、5分钟配置和来源登记；不把Chicago结果外推为中国居住气候验证，也不在本轮执行引擎。

## 验证与复现

采用三种证据：小规模真实代码连接（家庭→住房/生活A→B→问卷）、源到界面的内容核对（命令、身份、来源、字面变化及未计算状态）、反例回归（热状态伪装、越界访问、资料篡改、同日多方案和未改原表单）。另检查真实配对IDF能否编译，所有失败保留，不换B。

`VALIDATION.json` 给出本批构建、覆盖、编译及界面自查。它不证明总体代表性、物理成功、居民理解或正式问卷心理测量有效性。要补物理后果或开始新正式采集，需要各自的版本化输入与另行验收；本轮不以它们作为连接完成的条件。

当前生产修复版本另见[完整后果验证](FULL500_PHYSICS_REPAIR_VALIDATION.json)与[修复及补生成方法](PHYSICS_REPAIR_PRODUCTION.md)：当前500题后果齐全，3个原日期替换明确登记，旧45个工程未知状态为历史诊断，不能继续当作当前线上题目。
