# 项目设定的保留理由与适用边界

本文件登记外部方法不能直接识别的建模选择。文献对算法或对象接口的支持，不等于对项目数值的经验标定。数值真值以`ASSUMPTIONS.json`、`reference_environment.json`和具体作业输入为准；改变其中任何条件需更新配置身份并重新验证。

| 设定 | 保留理由 | 可替换输入或公开方法 | 适用边界与验证 |
| --- | --- | --- | --- |
| 房间矩形语法、中间层与南北暴露 | 使只给面积和房间数的参考场景有确定、可审计的外壳 | 可由有使用权的实测图纸或公开原型坐标替换；广州论文面积/卧室数用于有界校验 | 不是原始户型复刻；不适用于顶层、底层、复杂遮挡或任意高层风场 |
| 论文室内面积到分配建筑面积映射，公开因子1.18 | 两种面积口径不同，不能直接比值缩放或伪称同一测量 | 上游提供明确口径、因子及理由；没有依据时只运行项目参数化模式 | [1,1.5]是项目准入域，不是中国统计区间；整个物理住宅须通过尺度和卧室数校验 |
| 120 mm参考楼板芯层、门窗与表面属性 | 在替换几何后明确指定统一围护边界，避免隐式沿用未证明的结构分类 | 可用可核验的本地构造替换；DeST材料按真实引用关系提取 | 不声称保留全部源模型或符合当地规范；本轮未单独识别各材料热参数敏感性 |
| `SHGC=0.87SC` | 为简化玻璃对象提供显式标量近似 | 可用源SHGC、光谱玻璃及框参数替换 | 不保证角度、光谱、框边界等价；不得作为原玻璃全性能复刻 |
| 活动标签映射与体量比例 | 官方活动表给成人参照，家庭日历给活动类别；体量差异需显式表达 | 人体活动表已替代统一固定功率；可输入有依据的个体体量比例 | 默认成人1；公开儿童0.75为构造场景。全体比例Morris检验不能证明儿童特定参数准确 |
| 清醒在场启停照明与可切换杂项 | 没有可公开核验的逐设备开关日志，采用可解释的条件规则 | 照明密度采用中国论文；可输入独立逐设备状态、待机或实测密度 | 开关逻辑、常开冰箱及烹饪日历均为显式参考输入；论文总设备密度不额外叠加 |
| 成员联合日历、权限与共享名册 | 房间占用聚类不能识别每名成员的同日轨迹或资产授权 | 中国占用模板可作为上游候选；将来可接入有本地校准参数的活动随机过程 | 本模块不创造全国人口/设备分布；上游必须提供完整日历、名册与权限，违规输入拒绝 |
| 安装包络、通行带和0.1 m网格 | 以可独立复核的二维离散见证筛查空间 | 清空包络采用公开布局思想；尺寸可换为制造商要求，联合MILP替代贪心 | 网格无解只适用于声明的包络/方向/通行带；未完成状态不得解释为空间不足；不是施工合规 |
| 空间搜索与床位分配上限 | 给任意批次提供有界计算和可追踪失败原因 | HiGHS显式状态；可提高节点/分配上限并重新运行 | 不丢弃未完成家庭；不把任意规模解释为无限运行资源或保证每户可行 |
| 16岁操作资格与10 min装载/取出 | 明确执行服务所需操作主体和时长 | 可由目标研究的资格及服务资料替换并注册新协议 | 是参考操作条件，不是法律判断；不自动补照护者或访问权限 |
| 定功率程序、设备容量/COP和热比例 | 使程序与热源可逐项核对，参数由资产契约明确 | 允许输入有出处的机型数据；热泵拓扑/曲线采用官方示例 | 不代表中国机型实测校准，未实现任意变功率程序或完整产品认证 |
| 分层水箱的单加热器与直接热水出口 | 使用官方独立运行接口，使流量、节点与电量可回读 | 水箱容量、功率、散热、节点数及需求由上游给定 | 不模拟混水阀；出口热水升数不是混合淋浴水量 |
| 规定混合参数、机械补风路径和20 min排风延时 | 提供明确、质量闭合且共享于A/B的参考环境 | 原生压力网络用于结构替代；排风容量采用公开技术参考 | 未经中国气密性标定；门户比例Morris检验不穷尽所有延时或漏风结构不确定性 |
| AFN4 Pa等效泄漏、门参数及LowRise风压 | 压力机制需要明确系数和外部边界，现有输入无气密性测量 | 有实测压差—流量曲线时替换系数；本轮用原生AFN与质量闭合验证 | 机制有公开依据，所选组合为项目情景；不证明高层微气候、管网泄漏或当地实际ACH |
| 共同前史、恢复期、通知时点及验收阈值 | 区分干预效应、未恢复状态和数值依赖，并固定可复核判据 | 通过注册的前史、尾期及步长比较选择数值配置 | 阈值为工程精度要求；不等于人类接受、舒适阈值、实测精度或所有内部状态完全相同 |
| 两条Morris轨迹与五因子范围 | 以有限成本完成初步全局筛查，并保留非线性/交互线索 | 扩大轨迹和参数集、引入有依赖结构的联合采样应另注册 | 不提供稳定精确排名、总体概率或完整不确定性覆盖；模型材料、气候和人口联合参数不在本轮筛查内 |

此次公开数值验证覆盖三种住宅、夏冬六案例及注册的物理参数域。规模独立性来自接口和实现不读取历史1000户，不来自把六案例解释为全国代表样本。新增规模、气候、几何和参数组合必须接受同一构造与运行门槛，并按其研究范围重新做敏感性和收敛检验。
