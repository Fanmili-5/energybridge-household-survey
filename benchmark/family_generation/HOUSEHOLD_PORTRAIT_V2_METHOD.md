# 家庭画像语义验收 v2（独立候选，未发布）

历史记录：邻日日历与共享默认归属已在[家庭画像v3](HOUSEHOLD_PORTRAIT_V3_METHOD.md)修订；本文件及v2结果保留用于重放，不代表v3已接入A/B。

本轮只修家庭生成内部的偏好映射。六类、原家庭事实、住房设备、生活日程、已有50户500题A/B与封存后果保持原样。A/B算法、UI91、问卷与采集流程待下一阶段；不仿真、不生成1000户、不部署、不合入main。

## 成熟采样保持不变

沿用v1的高斯Copula/NORTA构造：共享标准正态因子与独立残差生成相关正态变量，再由标准正态CDF及离散分位数映射到偏好。

`Z_hj = lambda H_h + sqrt(1-lambda^2) epsilon_hj; U_hj = Phi(Z_hj)`。

[Ghosh与Henderson的论文第1节](https://people.orie.cornell.edu/shane/pubs/ChessboardOR.pdf)支持该成熟变换；[作者说明](https://people.orie.cornell.edu/shane/NORTASoftware.html)说明高斯Copula关系与相关矩阵的局限。我们没有实现论文题名中的Chessboard算法，也没有拟合实测家庭偏好。潜在相关系数`lambda^2`不等于离散偏好字段的相关系数。载荷0.7、均匀潜在边际、0.5语义阈值、10分钟与0.1℃网格均为实验参数。[设备级柔性研究](https://eprints.whiterose.ac.uk/id/eprint/165733/)仅支持分开物理特点、使用偏好与舒适要求，不支持本项目的具体公式或数值。

版本设为`within_class_joint_v2`，但随机键仍使用v1流。同输入、同种子、同载荷，各家庭、成员、设备的随机坐标完全相同，改变的是映射。[可执行参数及来源表](JOINT_SAMPLING_RULES_V2.json) · [文献核读范围](JOINT_SAMPLING_EVIDENCE_V2.json)。

## 两处修正与共享意见

| 项目 | v1问题 | v2规则 |
| --- | --- | --- |
| 稳定习惯 | 逐日期可行钟点取并集后重新取分位，混同长期取向与当天目标；具体反例19:30被汇总为11:50 | 家庭只冻结早晚取向；每日目标保留源日期、相对分钟、日偏移、完整日期时间及原释放/期限 |
| A接口投影 | 单一工作日/周末钟点可能与逐日目标不一致 | 仅当该时段所有逐日目标相同、无缺失且日偏移为0时才允许无损投影；否则保留原A参数并记`pending_A_interface`。本轮只在副本验证适配器，未生成新A |
| 机器改时 | `(1-节奏稳定性)*(1-操作负担)`混在一起 | 机器改时意愿=`1-节奏稳定性`；原声明不可移时则为0。映射到原50分钟等登记边界，不扩大许可 |
| 人工负担 | 怕多装取同时意味着机器不愿改时 | 操作负担单独用于装取变化及额外干预。允许“机器可商量改时，同时不愿增加装取” |
| 共享配置 | 类别默认可能覆盖明确家庭声明 | 明确家庭声明优先，EB参考只作缺省；原硬件与操作权限始终优先。AC制冷、制热、停机分开；40℃停冷哨兵不作舒适温度 |
| 成员意见 | 一些与设备无关的维度也列为分歧 | 只报告实际相关且属于受影响成员的意见：程序设备的节奏/装取、空调的温度/舒适敏感、热水的备妥取舍、EV的节奏/备妥取舍；不平均成同意 |

偏好范围是实验协商上下文，不是硬限制、接受概率、拒绝标签或B准入条件。旧`tradeoff`排名和继承参考字段为兼容而保留，明确标为reference-only；v2活动语义以独立轴、结构化`sampled_preferences`、原`authorization`及`member_negotiation`为准。

六类核心来自EB角色的项目操作化，家庭类别固定，成员不另抽A—F。类内维度与映射是公开实验设定，不能声称是人口比例、心理测量或由年龄/职业推断的真实偏好。

## 时间可行域与缺失边界

不改原衣物/餐具需求、程序、完整洗烘依赖、机器窗口、装取条件、日历、热水水量/温度、行程、连接或目标SOC。同一户十天使用同一随机坐标；逐日候选由同一分位映射到该日原条件的局部域。原自动一体机烘干依洗衣及原时长导出；分体烘干按原转移条件导出，不能独立乱抽时刻。

局部候选默认以原登记常用操作人为条件，不代表全屋资源排程，不代表其他合格者已经愿意接手。无完整链窗口、缺少邻日日历、共享软偏好与原窗口无法兼容时，保留空值和原因，不换种子、不新增帮手、不改变A。另用已声明的邻日日历和其他原有合格成员做信息诊断，绝不把诊断替换成新操作安排。

受访者资料由同一结构生成：长期习惯/取舍与原权限单列，原程序与SOC等服务要求保留；每日候选、原释放/期限及跨日信息单列。声明的热水约40.56℃是出水服务要求，与空调40℃停冷哨兵不同。成员偏好与共享默认不同写为“需要协商”，不写成工程错误或已经拒绝。

## 验收与重放

先0696、0756两户同类同配置家庭：种子0—7，载荷0、0.35、0.7、0.9，全部64份候选，不选最讨喜的。逐份与旧v1的冻结文件精确重放、对照同一潜变量流。再对原50户使用预先固定seed0/loading0.7生成独立候选，核对核心、原服务/权限、缺失、重复、意见与时间表示。

重复性只统计活动语义，不用ID、文案、精确温度、钟点、连续随机数或无关维度制造唯一性；同时报告去除空调后的重复程度。相同条件可以重复，缺额不补抽。验证证明画像的工程与语义一致性，不证明真人行为有效、全屋可调度或A/B/问卷已验收。
