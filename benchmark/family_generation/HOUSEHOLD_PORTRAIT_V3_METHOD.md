# 家庭画像v3：已有邻日日历与共享默认的归属

本轮只验收家庭画像。保留原事实、设备、日程、必要服务、权限、A/B和封存后果；不改A/B算法、UI91、线上或采集流程，不仿真、不启动1000户、不合入main。

## 1. 日历补充是读取原证据，不是重排生活

原画像只读取所选十天，某些洗烘的原交付期限却延伸到未选中的次日。新版`portrait_calendar.add_calendar_evidence`按原服务释放/期限确定需要查看的日期，从原已声明的邻日日历中补入可用性证据。

- 所选十天、习惯统计、原需求及期限保持原样；邻日只进入局部装入/完整运行/取出可行域。
- 保留原成员、合格操作人、忙闲日历；证据冲突、改动选定日期或哈希不符直接报工程诊断，不覆盖原证据、不换种子。
- 新证据通过原日历校验器验证，并记录来源路径、哈希、所补日期及仍缺日期。没有证据的日期继续未知。
- 同一冻结分位数在补全后的局部域上确定目标，仍保留源日期、跨日偏移和完整日期时间。可行域变大可能使原来已有值的软目标也变化；逐项报告，不声称只填了两个空格。
- 日期与钟点分开：原服务日有完整局部候选就优先该日，仅在当天没有候选时按原期限进入下一可行日；再在该日候选中映射早晚分位。此日期优先级是公开实验规则，不将“偏晚”解释成自愿跨日拖延。首次全跨日分位的901项变动诊断保留，不用重抽来隐藏。
- 不新增衣物或餐具需求、不增加到访或帮助者，也不把局部时间可行当成全屋可排程、个人同意或物理结果。

## 2. 不再生成一个与成员竞争的“匿名家庭人格”

六类核心和明确家庭声明优先。已有高斯Copula设备坐标解释为**该设备参考成员的情境偏好**，不再解释成另一个独立于成员的家庭意见。

每台设备先依据原声明确定受影响成员：洗衣/烘干/洗碗沿用原登记操作人；空调沿用原用房成员；热水/EV沿用原需求请求者，缺少请求者时才沿用原登记操作人。该规则与原授权层一致，不把所有在家者当使用者或帮手。

| 条件 | 默认与成员意见的生成关系 |
| --- | --- |
| 只有一位受影响成员 | 该成员的逐设备偏好就是设备默认；结构化坐标、机器改时、装取取舍、舒适或备妥取舍一致，不另生成一套相反意见 |
| 有多位受影响成员，原登记操作人属于其中 | 用其逐设备偏好作为参考，其他成员保留各自意见；参考不是共同同意或新操作安排 |
| 多人且没有上述操作人，原确认人也是实际受影响成员 | 用确认人的逐设备偏好作为参考，其他人的意见仍单列；确认角色不自动压倒其他人 |
| 多人且缺少可明确的参考成员 | 保留为参考、标注归属未知；不随机选人、按ID抢先选人或发明达成一致 |
| 明确的家庭共享偏好 | 条件化每位成员的设备偏好，例如共享不可移时使相应软改时意愿为0、明确制冷范围约束个人温度支持；不扩大硬件能力或原授权 |

单成人家庭的共享洗衣习惯与该成人的洗衣偏好来自同一结构。公共空调仍可有成人与孩子不同的舒适意见；孩子表达偏好不取得设备操作权。单人卧室也不会凭空产生使用者与设备默认的温度冲突。

不把“同一个成员在所有设备上都一样”作为一致性要求：例如洗衣偏晚、洗碗偏早可以并存。成员的总体潜变量只作为生成底层，不再另行展示成第二套逐设备意见。活动字段为`member_preferences.*.device_preferences`和设备`member_device_preferences`；旧总体`preference_context`标为latent baseline only。

原高斯Copula的家庭、成员、设备随机流不变，不加新抽样、不换种子、不平均投票、不按结果筛选。只有非参考成员的实际相关差异才写需协商，且不等于已经拒绝。原授权及确认门槛保持，不因为默认与个人一致而自动获得执行许可。

## 3. 哪些有算法依据，哪些是本项目规则

沿用[高斯Copula/NORTA成熟变换](https://people.orie.cornell.edu/shane/pubs/ChessboardOR.pdf)及[作者关于相关性局限的说明](https://people.orie.cornell.edu/shane/NORTASoftware.html)。[设备级柔性研究](https://eprints.whiterose.ac.uk/id/eprint/165733/)仅支持分开物理特性、偏好与舒适要求，不提供本项目数值。

六类核心与参考配置来自EB的项目操作化；潜在分布、载荷0.7、0.5语义阈值、软改时公式及本轮“默认归属”规则均为**实验设定，未经实测偏好拟合**。本轮没有提出新的随机算法，也不声称原论文验证了这套家庭决策规则。[参数与出处](JOINT_SAMPLING_RULES_V3.json) · [实际核读范围](JOINT_SAMPLING_EVIDENCE_V3.json)。
