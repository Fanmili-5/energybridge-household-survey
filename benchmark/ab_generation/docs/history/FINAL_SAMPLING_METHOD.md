# 新版最终分层取样：静态计划验收

本协议补齐 `examples/gap_supplement/tail_plan.json` 已固定的最终取样；不改日期、家庭、剂量、种子20261019、层顺序或配额，不运行EnergyPlus。输入是原三情境的完整A与未观测B结局的候选目录。验收完成不等于每层都有样本：缺额必须保留，检查流程通过与覆盖合同通过分开报告。

## 输入与冻结

两个夏季情境复用此前封存的完整候选；冬季A使用此前保留的同一A/A先导上下文，其内容摘要必须与原制热诊断一致。按原全24档配置生成冬季全部设备候选与联合请求，不能只拿已有10个制热见证参加取样。`final_inputs/REFERENCES.json` 逐个绑定上下文文件、原情境计划和原取样计划，冬季物理失败另列标签。

`static_sampling build` 在目录处理与首次取样前写入 `PRE_SELECTION.json`，记录计划与输入摘要、实现摘要、固定种子和“尚未取样、未读B结局”。输入目录不可覆盖。读取已生成目录时逐项核对A上下文摘要、完整规则摘要、B结局为空及候选来源；完整生成命令可独立从公开A重建，不需要住房模块或仿真引擎。

## 八步算法与边界

| 步骤 | 实现 | 为什么这样做 |
|---|---|---|
| 1. 纳入候选 | 全部单请求、全部已生成联合请求、每情境一个显式A=B对照 | 不只保留优化器最优项或静态成功项；联合无效也参加诊断层 |
| 2. 规范化指令 | `sampling.normalized_commands`：去内部控制ID、同值且相邻的控制区间合并，保留间隙、不同值和重叠多重性；任务/装取按规范JSON排序 | 去除表示方式造成的重复，同时保留真正不同的计划 |
| 3. 去重 | 对规范化完整B计算SHA256，以完整上下文摘要+B摘要作为样本ID，保留全部别名 | 同一上下文的相同B只计一次；不同家庭/日期/背景不能错误合并 |
| 4. 静态分类 | 核对原身份、演员、时长、过去、授权、程序链、机器/人/房间冲突、温控范围及已知总功率包络 | `admission=normal`只表示静态请求有效；冬季A物理失败仍在独立字段，不能改成物理通过 |
| 5. 独占分层 | 按原十层顺序，首个匹配层拥有整个匹配池，包括该层未抽中的请求 | 防止同一个B反复计入不同层；后面层可能因重叠产生缺额，必须报告 |
| 6. 固定取样 | 先家庭、再家庭内请求：按SHA256(`eb.tail.priority.v1`,种子,层ID,阶段,身份)升序取原配额，身份作平局次序 | 限制候选较多家庭对配额的支配；固定输入可复现，不按实际成功、收益或偏好排序 |
| 7. 全A复核 | 对每个已选B物化完整计划，用未加索引的参考检查器重算哈希、特征和约束，再查温控/功率；无效计划应被正确标为无效 | 诊断负例也必须核对原因；不能把“检查完成”写成“每个B均可执行” |
| 8. 固定回放 | 从封存目录索引按原计划回放一次相同选择，逐项比较ID、归属层、覆盖表和完整计划审查 | 这是确定性一致性校验，不是第二次随机抽样；失败不换种子补齐 |

固定哈希优先级是项目算法；文献不提供该哈希公式、种子或配额，也没有证明它是严格等概率抽样。输出的 `nominal_frame_inclusion_probability` 只是有限目录的名义两阶段比例，不可作为已验证的设计概率、人口权重或置信区间依据。两户、三个情境的覆盖不代表真实家庭分布，训练/评估拆分仍应以家庭为单位。

## 完整历史索引的等价优化

旧取样器对每个B重复复制、序列化完整A历史。本版 `sampling_index.CommandIndex` 缓存只读原始行的规范JSON和控制负载，按原规则合并区间并构造**相同的完整规范JSON字节**，SHA256定义不变；请求检查缓存原身份映射和过去的控制边界。缓存持有原对象引用，临时行不能因Python对象ID复用误命中。私有补丁视图不修改A，公开 `apply` 继续深复制隔离输入与输出。

`catalogue(indexed=False)` 保留原慢速参考实现。通过完整小目录、异常身份/时长/过去、控制多重性、嵌套Unicode、间隙和临时对象复用比较，并对已选计划使用原参考检查器。优化不改变候选、层顺序、样本ID、哈希优先级或约束；不以换一种去重身份绕开耗时。

## 覆盖、失败和缺额怎样验收

`final_sample/COVERAGE.md`列出每层原始匹配去重数、独占数、要求、抽中数、缺额；`RESULT.json`还完整列出九个轴的单轴及两轴水平组合的可用量、抽中量和缺项。生成器的两任务剂量覆盖、最终样本的轴水平覆盖、十层配额是三个不同指标，不能混用。没有宣称小样本是完整覆盖数组。

静态无效请求留在全部目录索引，已选负例保留其补丁、原因和审查；没有抽中的候选也不删除。冬季既有物理失败保留，可有静态有效的B，但不得推断已经改善舒适。旧版全部无效、无响应及物理失败继续保存在原 `validation/joint_tail`，`RETAINED_HISTORY.json`核对旧结果/选择及冬季失败记录的原文件摘要，不将旧B结局用于新取样。新B没有执行，不能给它们虚构实际无响应或物理失败标签。

`static_sampling recheck`默认检查流程一致性，即使存在缺额也能记录成功；`--require-coverage`额外要求十层合同及声明的生成覆盖通过，缺额则退出失败。两者都不启动引擎，不重抽。实际响应、能耗、账单、舒适和人类接受留给后续可选验证。

## 依据采用范围

- [加拿大统计局：Probability sampling](https://www150.statcan.gc.ca/n1/edu/power-pouvoir/ch13/prob/5214899-eng.htm)：支持分层及先群组再群内单位的多阶段结构；不是对本固定哈希样本的统计代表性或等概率证明。
- [Kuhn、Kacker、Lei，2012，NIST IR7878，Combinatorial Coverage Measurement](https://csrc.nist.gov/pubs/ir/7878/final)：支持对任意有限测试集明确测量已覆盖/缺失的因素水平组合；不以层配额达标推断全部交互覆盖。
- [Kuhn、Kacker、Lei，2010，NIST SP800-142](https://csrc.nist.gov/pubs/sp/800/142/final)及[Lei等，2007，IPOG](https://www.nist.gov/publications/ipog-general-strategy-t-way-software-testing)：提供因素与交互设计依据；本版仍是项目的确定性分层算法和原联合目录，不声称实现IPOG或全局最优。
- 设备使用约束、洗衣/烘干模型、原EB目的及授权沿用 [GAP_METHOD.md](GAP_METHOD.md)、[JOINT_LOAD_SUPPLY.md](JOINT_LOAD_SUPPLY.md)、`SOURCES.json` 与 `AUTHORIZATION.json`；不把实验参数写成论文原值。
