# 第二主线的生成设计与原EnergyBridge的关系

本模块研究的是：在同一家庭、同一天生活和同一事件下，具体改变哪些设备安排，会带来怎样的生活负担、费用、响应和服务后果，供后续人类或角色扮演者独立判断。它生成可审查的合成提案，不生成“家庭应该接受”的答案，也不是原EB控制器的运行结果。

## 1. 原EB提供的设计要求

依据固定提交`2b17ae63e613da776c93e900f5dace50d63a88a8`，逐文件身份、永久链接与用途见[原EB来源表](provenance/ORIGINAL_EB.json)。这里分别核对README、adaptive harness、问卷目的、呈现协议、中文题目和两个实现模块，没有把一个旧策略函数当成整个EB系统。

| 原EB的要求 | 本模块如何落实 | 不能据此声称的内容 |
|---|---|---|
| 无事件日常安排是拒绝提案的真实参照；不得将已优化提案重新命名为默认 | 先以生活、独立需求和习惯生成A，A生成函数不接收事件、电价、B、答卷 | A是实测行为或全局最优日常安排 |
| proposal→validation→consent→execution→outcome分阶段 | B请求、静态问题、假设应用B的物理后果和未知接受/满意度分别记录 | 配对仿真就是住户已同意并执行 |
| 可观察信息与隐藏角色/评价信息分开 | 本模块不按态度类别、期待接受率或满意度挑B；公开完整A信息特权 | 该离线生成器可以直接用于在线控制器公平排名 |
| 具体取舍由家庭判断，费用、舒适、服务和VPP是不同维度 | 保留分维度预测/实际结果、未知值和不利结果，不设“合格接受率” | 扰动排序就是人的效用函数，成功响应就是满意 |
| 原EB的模型拥有开放规划与选择；工具不暗中替模型选答案 | 三种确定性规则明确标为合成方法对照，没有冒称EB agent | 三规则复现了EB、HEMA、MPC或RL的表现 |
| 原问卷呈现实际方法生成的动作及其真实说明，先判断后看结果 | 本模块只供离线审查；将来若使用须标明synthetic，文本须对应命令及实际后果 | 能把合成B贴上EB方法名，或补写个性化说服说明来冒充原输出 |

原EB有单人六角色的问卷协议。本项目家庭化服务链是新的实验扩展，成员冲突、共同决策和共享电表归属不因继承角色名称就已经得到人类验证。六类态度比例也不从本生成器推断。

## 2. A的设计目的及准入

A回答“这家人在没有本次VPP干预时，按已经声明的当天生活和习惯会怎样安排设备”。其生成顺序为：

1. 固定家庭成员、设备能力、使用权、原日历、出行和空间资源。
2. 从衣物库存、餐食、洗浴、占用和出行形成独立需求；数量、期限和温度要求具有各自来源。
3. 在原可操作窗口内安排装载、完整程序、取出、真实插拔和温控习惯。习惯锚点是软排程代价；硬件、物理连接和声明服务包络是约束。
4. 完整需求无可行安排时保留失败，不删需求、不造帮手、不重抽家庭。构造通过后仍须执行并审查A，才能作为正常配对的基线。

库存、机器程序、控制命令、实际服务以及家庭愿意接受的变化各是独立对象。不能从A习惯或A可行性反推出可接受移时/温差。已声明的温度和出发目标在结果中单独检查，未知要求保持未知。

## 3. A到机会：证据必须分层

本版是[完整A离线反事实实验](OFFLINE_EXPERIMENT.md)。热设备机会读取A原生运行通道；程序设备读取真实程序与装取链；EV读取原连接内的充电及后续交付。实际运行、名义余量、静态可改、改变后有效是四个层次。

对外部固定事件，没有合适机会就是没有，不移动事件、不添加服务。旧B60中的“资源条件化联合情境”是另一种构造实验，不能混称真实调度频率；当前新生活接口只使用给定事件。无设备、缺权限、缺原生模式、无可操作窗口和不支持的模型均保留原因。

## 4. B的设计目的与构造

B回答“在这些原资源上，提出这一组具体改变，如果应用，会有什么后果”。先枚举、再按冻结实验规则取提案，最后计算后果。A及独立需求不随B重写。

| 设备 | 可提出的改变 | 必须保留的条件 | 必须另算的后果 |
|---|---|---|---|
| 洗衣/洗碗/关联烘干 | 定时启动或完整人工链移时 | 批次、原操作者、非中断程序、释放、装取、依赖、整段资产占用 | 等待、交付/截止、实际电量与费用 |
| AC | 指定区间双设定变化，区间外恢复A | 原设备、控制权、另一轴/风机、死区；不改原占用 | 原生电耗、室温轨迹、已知温度要求外分钟与恢复 |
| 储水热水器 | 原设备控制目标在指定区间变化 | 原洗浴、用水数量和最低交付温度、硬件上限 | 出水服务、箱温、电耗与恢复；不由设定值保证 |
| EV | 暂停原许可的剩余部分 | 原行程、原插拔和许可间隙、出发目标、效率/容量 | 连续SOC、出发目标/牵引/储备、费用及恢复 |

正常候选要求通过当前静态执行包络，反向请求、费用增加、零/负预测收益不据此删除。静态问题候选仍在目录中；明确的故障探针须事前列出允许问题，单独执行并标明失败，不能伪装为正常可部署建议。输入/模型错误须修版本，不能当作家庭偏好差异。物理/服务失败也不等于“人会拒绝”的已知标签。

习惯偏离只是负担维度。允许用户评价的软偏好不自动成为数据无效理由。当前预装/取出上限、机器窗口和独立服务期限是显式声明的实验包络；若以后要研究违反这些承诺的提案，必须新建标明风险的实验分支，不能悄悄放宽普通候选的约束。这里没有独立人体安全阈值认证，已声明舒适范围不能冒充医疗安全标准。

## 5. 提案选择与实验覆盖

当前有三条透明路径：同一候选池上的三规则对照、冻结计划中的设备/联合/故意失败探针，以及按事前分层抽取的长尾样本。前者比较最小命令扰动、已知程序/EV费用和已知程序/EV事件电量；后者补足热设备与失败边界。三规则是有变化B中的条件比较，A不变外部选项另列；不保证三份命令不同，不作全设备全局优化或人类效用最优声明。

不同取舍应来自可核查的因素组合，不能靠文案改名制造。实验设计先固定家庭与A，再固定事件/价格、剂量、方向、设备族、选择准则和种子；保存全部缺失、重复、静态失败和实际失败。不得在看过最终B结果或答卷后只留下省钱、成功、易接受案例。新研究的覆盖配额及随机化须另行预注册，不能将当前三个合成家庭当作代表性样本。

当前公开审查已执行三种规则、四类设备探针、联合请求、冬季制热和一个EV出发目标失败；普通三规则的命令差异主要来自刻意对比的EV电价情境。它证明接口和边界可执行，没有证明家庭取舍的完整分布。新增的长尾路径在 `TAIL_METHOD.md` 中固定去重、两阶段取样、失败准入与覆盖验收；实际验证范围及剩余缺口见 `TAIL_VALIDATION.md`。参数敏感性、总体分布和人类理解仍待验证；不能用静态目录计数代替物理或人类验证。

## 6. 实际后果及人的位置

冻结B后，同一物理世界、天气、初态和前史执行A与B。逐通道核对配对A与生成时的A参照，报告主区间与跟随期费用/电量、事件两种电表口径、服务、温度、水和SOC；不完整运行保留未知。拒绝参照为A，接受参照为假设应用B的结果；本模块没有实际征求或模拟同意，也未实现原EB的再规划/承诺记忆闭环。

未来的离线评价应先只显示家庭、事件、A/B动作差异和可在提案时支持的说明，再收集接受判断；其后才揭示对应结果并独立收集满意度。人和LLM须用语义一致的角色与信息，方法身份/隐藏分数不得泄漏。授权、伦理及呈现审查完成前，本次仅更新研究代码与文档，不接入线上问卷。
