# 新联合目录的公开验收回执

正式结果为17/18个必验层通过，覆盖合同未通过；不是训练或线上发布许可。见 `STATUS.json`、`COVERAGE.md` 和上级 `JOINT_TAIL_VALIDATION.md`。

- `frozen_inputs`：8个合成A语义上下文、原生A来源哈希与序列化对应，支持取样重放。未包含早期B后果。
- `frozen_sample`：执行前固定的19条选择、22层计划、16份生成覆盖及参考A回执的公开审查视图，选择内容未改。完整变体可由冻结A重建，别名路径指向重建后的变体目录。
- `CATALOGUE_INDEX.json`：全部9,275条唯一请求的身份、特征、静态问题和来源别名，不只保留成功B；完整字面补丁见重建目录或原始封存。
- `OBSERVATIONS.json`、`RESULT.json`：17组完整实际读回及所有19条的去向，含无响应、混合响应、服务失败和静态诊断。
- `INTERACTIONS.json`：1,802个单/双因素格，包含928个未选中格。它们是目录可用但本次未抽中的格，不能混称生成器未产生该类请求。
- `INPUT_SCOPE.json`：工作日/降载等输入范围及尚未验证水平，不是事后变更配额。
- `RAW_CHECKS.json`、`SELF_CHECK.json`、`REPLAY.json`：冻结选择、字面任务和原生A完整性、重算及精确重放证据。

`recompute.py`只重算封存观察，不重新选B或运行引擎。默认检查重算/完整性；`--require-coverage`为严格覆盖门，本版应非零退出并保存缺额。不同平台重新仿真的A哈希可不同，不能据此要求新A仍抽中相同案号。

这些是合成输入及项目生成回执，不含答卷或新的人类同意。LARCO引用、许可和变换声明在邻级 `joint_load_supply/README.md`；这里不额外发布其家庭、音频或天气数据。原生SQL、IDF和日志保存在本地封存证据，永久复现依据为公开输入、代码版本、官方引擎及方法文档中的命令。
