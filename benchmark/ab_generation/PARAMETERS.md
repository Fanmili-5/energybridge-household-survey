# 第二主线参数依据与使用边界

[PARAMETERS.json](PARAMETERS.json)逐项登记24个生成器默认键、生活Schema的105个字段约束，以及全部29个公开JSON输入中的593组数值/布尔字段：值、出现次数、用途、来源类型和实现位置。数组索引用`*`合并，保留所有不同值；具体家庭、日期、资产由带SHA的原输入精确定位。身份、枚举和字符串规则在Schema及来源文件中保留。这不是对1000户或原50户全部参数重新校准的声明。

## 默认参数的理由

| 参数 | 当前值与用途 | 依据和局限 |
|---|---|---|
| 行为/人工操作分辨率 | 10分钟；一次装取/插拔占一格 | 接口一致性与人工资源占用的实验简化；未测量真实操作时长 |
| A排程代价 | 习惯偏离1、预装等待0.4、取出等待0.5 | 项目确定性比较；靠近习惯并减少等待；不是文献估计或人的效用，未做权重敏感性研究 |
| 种子 | 20261019 | 固定并列选择；不代表总体随机抽样 |
| 程序移时 | −120/−60/−30/+30/+60/+120分钟 | 在A附近形成方向/幅度不同的有限提案；约束不允许时保留静态失败 |
| 人工模式 | `timer_only,shift_chain` | 分离机器改时和人工负担；不能添加未知定时能力或更换操作者 |
| 温控剂量 | 0.5/1°C × 20/60分钟 × 顺向/反向 | 紧凑的机制/边界比较；不代表可接受温差，也不保证实际温度或电量效果 |
| EV暂停 | 30/60/120分钟 | 在原连接/剩余许可内比较；原能量不足时标静态失败 |
| 热活动阈值 | 0.001kWh/10分钟 | 项目近零筛查，约该步平均6W；不是仪表精度、交付下限或居民感知阈值 |
| 三种排序 | 命令扰动、已知费用、已知VPP | 合成对照，不是原EB模型选择；热响应费用/VPP预测未知，不以额定功率补齐 |
| 扰动字典序 | 人工变化→温差×命令时长→程序/充电移时 | 项目排序会偏向不改人工的请求，不代表所有家庭的跨设备效用 |
| 联合族数 | 最多2 | 限制复杂度；常规规则仍选单设备，联合探针另列 |
| 排序等价级 | 费用及kWh各1e−9 | 只消除浮点伪差异；保留原预测/后果，不代表人的无差异区间 |

确切剂量和权重均为项目设定。Chen、El Makroum和Wen分别支持分层负荷建模、生活/费用取舍及情境评价的研究结构，没有提供本项目这些确切原值。原EB也没有替这些值提供人口校准。

## 声明输入与模型边界

日历、衣物进入量/容量、程序时长、洗浴量、期限、机器窗口、等待上限、控制习惯、舒适要求和原出行须显式给定，公开示例中的值属于合成情境。能力、权限和独立服务承诺按约束检查；习惯锚点是排程代价；人的接受程度未知。不得用A可行性、态度类别或已有排程反推缺失许可。

历史A46适配器的定时允许、720分钟预装和06:30—23:30机器窗口是固定项目规则，来源原文现可公开按SHA检查；不是每台真实机器的规格证明。新生活输入不自动继承这些值。

Schema温度/时间界限是模型输入范围，不能称作人体安全标准。运行时还检查有限数值、硬件最大温度、双设定次序、完整日历、权限、资源冲突和能量守恒。此次补齐水箱回退目标上限、温控Schema范围一致性和非有限温度拒绝；合法样例不因拒绝规则改写。

天气、硬件、背景负荷、热分配、前史、求解步长和尾期由公开文件绑定。其来源与验证范围委托住房模块的[SOURCES](../housing_simulation/SOURCES.json)、[方法](../housing_simulation/METHOD.md)和[验证](../housing_simulation/VALIDATION.md)，不在第二主线重新认证。当前112日前史、5分钟求解、9日尾期按登记情境解释。

完整未来A是[离线实验信息特权](OFFLINE_EXPERIMENT.md)。模型设备权限、来源可见性、代码/数据许可、实际住户同意和伦理批准须分别有依据，见[AUTHORIZATION.json](AUTHORIZATION.json)。本次不授予统一开源许可或新增线上操作权限。

`python -B -m benchmark.ab_generation.audit_design`检查默认参数、Schema、全部公开输入及历史来源与登记的一致性。新增/改值后须更新依据和验证记录，不能仅改哈希就视为已校准。

## 当前机会与覆盖的附加设定

`opportunity_algorithm_settings`登记解析剖面判等1e-9 kWh、温控见证1e-9°C、原生回读电量1e-9 kWh及温度/SOC状态1e-7（对应单位）。它们是数值守卫，不是服务能力或人的感知阈值。窗口代表为原最长最早和支持优先最长最早，不是连续空间穷举。当前覆盖计划要求六类设备变化，并设有依据目标的无响应比例上限0.5；该“拒绝多数退化”预算由项目提出，论文没有提供原值。全部不确定、无效及失败样本继续保留。缺额、阈值敏感性和实际连续差异见[RULES_VALIDATION.md](RULES_VALIDATION.md)。
