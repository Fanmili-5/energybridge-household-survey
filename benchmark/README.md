# EnergyBridge 参考家庭偏好基准

本项目让参与者扮演给定家庭，比较日常方案A与VPP调整方案B，提交四项评分、接受判断和原因。研究对象是**在相同角色、方案与可见仿真信息下的家庭评价**。仿真达标、能耗减少、约束可行性都不直接赋成人类接受标签。

当前版本为`reference50-v1`，问卷UI为V69。50户500组是同一1000户10000组主数据的原比例子集，不是另外生成的一批。A46/B57及现有物理V61、影响摘要V62保持。

| 对象 | 规模与关系 | 当前状态 |
|---|---|---|
| 1000户主数据 | 1000户、10000组A46/B57，包含下列50户 | 生成输入已固定；本版全量仿真及标签评测尚未完成，继续暂缓 |
| 50户参考版 | 同源50户、500组；六类5/15/16/5/4/5 | 已有本版物理和影响摘要；用作当前采集与工程基线 |
| 当前在线版 | 每名参与者固定一户、10个日期 | 免邀请码；无时间轴；可保存、恢复、修订和撤回；质控另行记录 |
| 历史12人试填版 | 6户、18个案例、36份计划评价 | 已被完整50户入口替代，不能当作已收集36份有效答卷 |

唯一当前入口：[50户问卷](https://47.85.194.154/household50-current/)。旧`/household50`、`/household950`及V23—V30的验收属于历史版本，不证明A46/B57全1000户已通过。

## Benchmark 构造模块

[住房与仿真场景生成](housing_simulation/README.md)提供建筑参数参照、面积约束外壳、家庭世界自动装配、A/B编译、引擎执行及物理审计。公开配置可从外壳连续生成包含成员、设备、日程与服务的完整物理世界，并独立复现三对非空A/B仿真。代码、输入Schema、来源与规则登记、正式方法及验证证据随模块提供；规模由输入列表确定，不读取历史1000户。已发布参考数据集作为应用版本单独管理。


[日常A冻结与B候选生成](ab_generation/README.md)提供当前A运行绑定、设备原生候选、事前选择及配对物理交接。该模块为独立的方法实验版本，不替换当前参考数据或问卷；构造依据、实验参数、复现命令及验证范围见模块技术文档。
