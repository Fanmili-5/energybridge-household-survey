# EnergyBridge 参考家庭偏好基准

本项目让参与者扮演给定家庭，比较日常方案A与VPP调整方案B，提交四项评分、接受判断和原因。研究对象是**在相同角色、方案与可见仿真信息下的家庭评价**。仿真达标、能耗减少、约束可行性都不直接赋成人类接受标签。

线上仍为`reference50-v1`，问卷UI为V69。50户500组是同一1000户10000组主数据的原比例子集，不是另外生成的一批。A46/B57及现有物理V61、影响摘要V62保持。

**2026-10-20已封存待上线：[新版50户提案采集版](releases/reference50-v4-proposal/README.md)。** 保留原50户500条A，采用新版B和固定18—19时段；后果全部标为未计算，可后续对冻结A/B另做成对仿真。此时采集的是物理后果展示前的角色判断，与旧版带仿真信息的采集条件分开管理。尚未替换线上问卷。

## Benchmark 构造模块

[家庭六类偏好方法 v1](household_archetypes/README.md)是第一条方法主线：沿用EB六种预定义角色，通过ECA、iFlex、荷兰和eCAPE原始问卷核查组成维度及部分同人共现，明确实验设定和不能恢复的类别。EB角色分配人数与最大余数法支持可复算的拟议配额；该配额不是人口比例，也尚未迁移到现有家庭。此模块定型不替代当前数据、A/B生成或住房仿真的验收。

[住房与仿真场景生成](housing_simulation/README.md)提供建筑参数参照、面积约束外壳、家庭世界自动装配、A/B编译、引擎执行及物理审计。公开配置可从外壳连续生成包含成员、设备、日程与服务的完整物理世界，并独立复现三对非空A/B仿真。代码、输入Schema、来源与规则登记、正式方法及验证证据随模块提供；规模由输入列表确定，不读取历史1000户。中国户型/照明参考、联合安装与原生压力网络的依据及边界逐项登记；`study`执行夏冬六案例的Morris敏感性及数值收敛。已发布参考数据集作为应用版本单独管理。


[生活安排、日常A与B策略生成](ab_generation/README.md)提供声明的人员日历与生活条件→独立服务需求→可执行A→当前A运行绑定→设备原生B候选→同世界配对仿真的通用流程。输入规模由列表确定；衣物库存、真实装取、独立烘干、房间占用、热水与原EV连接分别建模，无法满足的需求保留。公开小样本用于方法与物理集成验证，仍为独立实验版本；构造依据、人工设定、命令与验证边界见模块文档，不替换当前参考数据或问卷。
