# EnergyBridge 参考家庭偏好基准

本项目让参与者扮演给定家庭，比较日常方案A与VPP调整方案B，提交四项评分、接受判断和原因。研究对象是**在相同角色、方案与实际可见资料（含未计算状态）下的家庭评价**。仿真达标、能耗减少、约束可行性都不直接赋成人类接受标签。

原50户500题已准备**UI91立体房间与完整配对后果**，当前入口暂停等待核验切换。每户十个不同日期，VPP固定18:00—19:00；500题均有可用估算，80题达标、420题未达标，100题服务或恢复问题照实保留。497条原选题不变，3条按事前工程补生成流程换为原全年A的新日期切片；原失败记录、设备和全年A保留，旧答卷不迁成新版答案。1000户继续暂缓。

当前入口：[50户问卷](https://47.85.194.154/household50-current/)。新版独立采集库，旧版资料与记录保留。此时评分是物理后果展示前的提案判断；后算仿真不得写成参与者当时已知的信息。

原A46/B57的1000户及旧50户参考物理结果仍是历史归档，新B不是旧B57主集的内容子集。950户新方法尚未生成，1000户继续暂缓。

## Benchmark 构造模块

[家庭六类偏好方法 v1](household_archetypes/README.md)是第一条方法主线：沿用EB六种预定义角色，通过ECA、iFlex、荷兰和eCAPE原始问卷核查组成维度及部分同人共现，明确实验设定和不能恢复的类别。EB角色分配人数与最大余数法支持可复算的拟议配额；该配额不是人口比例，也尚未迁移到现有家庭。此模块定型不替代当前数据、A/B生成或住房仿真的验收。

[住房与仿真场景生成](housing_simulation/README.md)提供建筑参数参照、面积约束外壳、家庭世界自动装配、A/B编译、引擎执行及物理审计。公开配置可从外壳连续生成包含成员、设备、日程与服务的完整物理世界，并独立复现三对非空A/B仿真。代码、输入Schema、来源与规则登记、正式方法及验证证据随模块提供；规模由输入列表确定，不读取历史1000户。中国户型/照明参考、联合安装与原生压力网络的依据及边界逐项登记；`study`执行夏冬六案例的Morris敏感性及数值收敛。已发布参考数据集作为应用版本单独管理。


[生活安排、日常A与B策略生成](ab_generation/README.md)提供声明的人员日历与生活条件→独立服务需求→可执行A→当前A运行绑定→设备原生B候选→同世界配对仿真的通用流程。输入规模由列表确定；衣物库存、真实装取、独立烘干、房间占用、热水与原EV连接分别建模，无法满足的需求保留。公开小样本用于方法与物理集成验证，仍为独立实验版本；构造依据、人工设定、命令与验证边界见模块文档，原参考版归档；当前50户采用该方法的v4生成和选题。
