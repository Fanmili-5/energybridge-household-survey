# 参考住宅构造与适配规则

本系统为 Roleplay 和控制实验构造可复刻的物理参考情境，不复原每个调查家庭的真实住宅，也不据此估计国家平均能耗。

## 一套规则，三个共享输入

1. **模板算法**负责几何和住宅上下文。固定 OpenStudio-HPXML 提交根据参考空调面积、住宅类型、户内层数、共墙和上下暴露生成住宅；不缩放 IDF 顶点，不从国家名称猜邻接。
2. **完整参数包**负责围护和设备。地区设计依据选择完整命名构造，保留层序、厚度、导热系数、密度、比热和表面属性。窗的 U 值与 SHGC 来自同一公开选项。中国 A1 安装完整来源的墙、窗、屋面与楼板，顶板采用显式反向层序。不能只换天气或从一个 U 值反推墙体。
3. **地点包**负责 EPW、引擎实际地点、站点身份、时区和当地标准时间、进水、设计工况及地面/地形依据。公开 Kiva 土壤和基础属于参考实验条件，不声称当地地块实测。

调查事实、匹配信息和参考设计分别保存。未知真实面积、楼层或构造保持未知；实验参考值有独立字段、来源和显式选择依据。

## 编译过程

`住房条件 → 类别解析 → 模板与地区包 → 来源构造 → 地点与设备安装 → EB 控制 → 官方 EnergyPlus → 输出检查`

`scripts.run_shared_housing` 自动选择完整类别，然后调用已有 `reference_pipeline`。底层接口保留给工程检查，不能绕过地区包选择后把裸房壳称为地区适配完成。

围护改造按对象引用、表面角色和边界执行。共享构造引用、反向层序、门窗依附表面与公开构造器的微小辅助表面单独处理。每次改造输出原值、新值和来源绑定；保留几何及边界，不补固定邻居温度。

设备沿 EB 任务、控制与计量组织方式接入。区分物理存在和可控，缺席设备不安装，后台设备保留声明服务。共用洗烘资产有相同资产标识、排他运行和任务依赖。明确移除被替换的旧负荷，核查电、水、热湿及热水归属，避免重复计量。

空调继续使用来源支持的容量、部分负荷、温度域及化霜模型；越域和能力不足要报告。原 EB 120 L、3 kW 单节点电热水箱保持原模型，不为改善收敛升级复杂度或增加隐含加热。EV 保持接插、SOC、充电损耗及出行能量的连续账。

CASE v3 按日期读取需求；不能把首日需求重复成后续所有天。生活输入、控制输入与固定物理配置分离，运行请求不能改材料、曲线、邻居边界或设备性能。

## 来源与地区差异

共同公开构造器提供完整物性。各地区依据负责选择参考设计，不能把构造器源自美国解释成八国存量材料相同，也不能把不同来源差异直接解释为国家行为差异。

| 包 | 选择依据与边界 |
| --- | --- |
| CN | 公开 A1 完整层构造；广州、上海参考条件，不代表中国全部住宅 |
| US | 固定 HPXML 完整构造和公开参考选项；Denver 示例 |
| GB | England ADL2021/2023 设计限值选择完整构造；London，不扩大到全部英国地域 |
| ES | CTE DBHE2022 D 气候设计约束；Madrid |
| DE | GEG Anlage 7 构件改造限值；Berlin，不作整栋合规认证 |
| MX | NOM020-2011 Mexico D.F. 参考行；实验几何不同，不作整栋合规认证 |
| IN | ENS2018 暖湿区屋面与 RETV 约束；Mumbai，未知墙/窗 U 限值保留 null |
| AU | 政府托管住宅节能指南启发的参考设计；Sydney，不声称美澳评级等价或 NCC 认证 |

具体数值、层物性、完整选项、换算和来源哈希见 `parameters/`。澳大利亚原 PDF 未完整取得，包中注明摘录依据和证据限制，不能称全文核查完成。

## 验证、复用和拒绝

检查面积口径、体积、闭合和邻接、引用及材料层物性；检查传热、蓄热和温度响应方向；检查旧负荷清理、设备及整户电量、水和热水/EV 能量账。需求超过设备能力时报告服务不足，不制造能量补齐。

新 CASE 沿用原 1/2/5 分钟、14/28 天预热和 7/14 天恢复比较与阈值。软件测试只检验相应接口逻辑，正常退出只说明引擎运行；二者不能替代物理与数值结论。

完全相同的固定物理定义可以复用住房和安装包。结果缓存还必须绑定完整需求/控制、代码、资源及原生输出；只改家庭标签不改变物理，改需求也不要求重建房壳，但新请求不能借用其他请求的数值通过标记。

缺面积、来源冲突、户界或安装条件冲突、未注册地点、未知设备性能、越域或数值失败均明确返回。公开目录中的类别不等于该类别所有连续面积、层数、日期或服务需求均已通过。

## 扩展单位

- 新家庭：复用模板和共享包，单独接入需求及控制。
- 新面积、楼层或邻接：同一构造算法生成，检查该组合，不另找材料或逐户修改设备。
- 新地点：增加共享地点包并确认与地区构造、设备域兼容。
- 新气候、围护、基础或邻接类别：版本化扩展完整包与规则，先核来源，再做代表性原生验证。

本模块不生成家庭、不设计最终 A/B，不把室内整户温度解释为房间或个人舒适，不把程序完成解释为真实洗净/干燥质量，也不产生人类偏好金标准。
