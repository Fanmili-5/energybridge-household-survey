# v2.11：原50户500日期影子选题验收

使用固定v2.11核心、配置和种子，对原18,977份候选新增分维度解释，并在50户各十个原日期中重新选题。每个日期恰好一题；A/B字面动作、原家庭、日程、设备、服务需求均未改变，没有补抽候选或日期。旧v2.10选题与最初原生选题均保留。

本页只公开无身份汇总。完整逐户表、500日期记录、解释、别名和选择轨迹保存在本地授权资料中，不公开家庭ID、日期、题目ID或个体画像。

## 主检查结果

- 18,977份候选、29,494项动作实例均重新通过独立工程、因果、机器/装取字面变化、十分钟准备阶段核对，错误0。未排除任何原候选。
- 50户均达到独立日期—规模最大匹配上限，合计200项家庭内规模见证，联合规模缺额0。
- 1,264项冻结规则下的选题目标全部覆盖；三层MILP均证明所声明目标最优。它是目标函数的最优，不是行为真实性或人类接受的证明。
- 与实际v2.10影子选题相比，95个日期改选另一份原候选。反转全量输入顺序，同种子重放一致，没有挑选最好种子。
- 原3,850份保护文件及584份读取来源哈希不变。语义签名的同户重复超额0；该代理未经真人验证，不代表受访者必然认为不重复。

## 额外细分组合缺额：仍未全面覆盖

主选题目标是按设备族归一化的分维度覆盖，并未把所有“机器×装取”组合列为选择目标。因此额外检查发现：全局22种已有设备族/幅度组合只选到17种，缺5种；按家庭分别条件化，则245项家庭内已有组合只选到115项，仍缺130项。完整逐户缺额保留在本地。

这些是选题后增加的描述性诊断，不是看到结果后修改的验收目标，也没有用它重新选题或改权重。不能把1,264项声明目标无缺额写成所有联合幅度都覆盖。

## 分母、偏置与复现边界

输入侧5,453项potential机制均有候选见证，最终题选入926项，4,527项家庭日机制未入选；4,176项输入机制证据不足继续保留。它与按十日归一化的选择目标不是同一分母，不能称为全机制覆盖。

原生成目录仍有3,525,721项条件交互未知或未探索；该数量按原分区/原版本封存，不是新v2.11分维度分区的分母。本轮没有重新生成或扩搜候选，也不能主张完整控制空间已覆盖。

五个已出现设备族的细节总权重均为0.2，空调描述字段多不会增加该族总权重；不要求各族题数相等。没有按费用、成功或预期接受程度筛选，没有预设正常、冲突、失败配比。覆盖取样不表示自然人口比例。
