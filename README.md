当前基线是**50户、500组A46/B57**，每名参与者评价固定一户的10个日期。免邀请码、无时间轴，四项评分、接受判断及原因必填；支持保存、恢复、修订、撤回和版本化人工质控。

## 数据如何生成

有来源约束的家庭骨架和住房 → 设备与支持边界 → 上游生活日程 → 正常A → 同需求下的VPP调整B → 同版A/B仿真 → 能耗、生活和客观VPP摘要 → 家庭角色评价。B可失败、不利或被拒绝；客观达标不等于接受。

## 家庭生成与上下游连接

[家庭生成模块](benchmark/family_generation/README.md)公开完整联合参考情境、EB实验配额、成员/关系/设备/权限契约和同源子集的可运行入口，可连接住房与生活A。代码、合成示例、许可、输入锁、反例测试及历史1000户只读审查分别提供。公开六条情境用于接口验证，不是人口样本；旧50/1000户未迁移，尚存的关系与内核兼容边界如实列出。

## 家庭六类偏好方法

[第一条方法主线 v1](benchmark/household_archetypes/README.md)固定EB六类的来源，逐类区分外部问卷依据、实验设定与实际验证结果，公开EB实验构成的配额计算、原始输入版本/哈希、离线重放及论文方法表述。外部调查支持相关特征与部分组合，不代表完整六类或人口比例已验证；拟议配额尚未应用于现有50/1000户，当前家庭、排程、仿真、费用和线上版本保持，1000户仿真继续暂停。

## 独立住房与仿真生成

[住房生成模块](benchmark/housing_simulation/README.md)提供不依赖历史1000户的完整物理构造流程：参考外壳、成员与设备自动装配、日历和服务绑定、A/B编译、EnergyPlus运行及统一审计。公开非空实例可复现三种家庭场景；输入Schema、算法、来源依据、项目规则及验证结果对应发布。该构造模块与上表中的既有数据集版本分别管理。新版补充中国户型来源域、活动负荷、联合安装求解、压力网络结构比较，以及先登记的敏感性与数值收敛流程；方法采用范围与项目设定逐项说明。

## 核验当前公开版本

```bash
python -B benchmark/verify_publication.py
python -B benchmark/collector/test_protocol.py
```

公开clone可核验源码、50/1000同源摘要与HTTP采集协议；测试只用虚构临时数据，不跑EP、不创建真人标签。获准研究工作区可按[采集器说明](benchmark/collector/README.md)构建、验证及部署对应受控资料包。

公开内容是当前代码、方法、格式、聚合证据和输入哈希。调查、逐户受控包、住宅/天气原件、完整EP输出及真人记录不在Git中；取得许可原件不自动意味着可以再分发。[来源与许可](THIRD_PARTY.md)

当前不是已完成真实标签、独立测试集和模型成绩的论文benchmark发布。具体划分与正式评测指标待确认冻结，工程测试与物理参考不能替代真人理解和研究有效性。
